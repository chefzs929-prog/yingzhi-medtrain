## 四、三个必须今晚就知道的风险

### 风险一（红线级）：被判定为"壳工程"

赛制第 5 条原文：**"作品核心链路（知识库接入、技能与工作流编排、Agent 运行）必须在 DeepWorks 内实现，禁止以外部框架或自建后端作主体、只做界面包装的'壳工程'。决赛现场须在 DeepWorks 环境内实时演示。"**

现状对评委不利的三点：

1. `README.md` 自己写着"纯静态：页面不调用大模型"——这是主动把刀递给评委；
2. `yingzhi/serve/` 下有 `gateway.py`、`llm.py`、`vision.py`，看起来就是一个自建后端；
3. `.opencode/deepworks/outbox` 是空的，没有任何 DeepWorks 会话导出、交付物或截图。

你的实际情况其实比材料呈现的好：`docs/Agent接入指南.md` 写明了调的是 **DeepWorks 内置 opencode server**（`dth/Auto`，实测 7–9 秒四段式带 id），服务层只做转发与记账。这个论证是对的，但它现在**藏在 docs 里，评委会看不到**。

必须做的三件事（按顺序）：

1. 在 DeepWorks 里实跑一次完整链路并**录屏 60 秒**：`retrieve-sign` 技能被加载 → 4 条 grep 检索 → 四段式回答带 `SIGN-xxx` → 打开对应病例分区核对。这段视频就是"DeepWorks 使用证明"。
2. 说明书里用一张图把边界画清楚：**DeepWorks 内 = 知识库接入 + 技能 + Agent 编排 + 模型调用；站外 = 只读展示层**。一句话："站外页面不含任何模型调用，它不是主体，是展示壳。"
3. 把 `yingzhi/serve` 的定位改成"只读转发 + 记账，不含推理"，并在附件里给一张调用链时序图（浏览器 → 本地转发 → DeepWorks 引擎 → 模型）。

### 风险二（失分最大）：实用性没有用户

模版对实用性的三问是"能不能完成真实任务 / 流程合不合理 / 有没有样例或用户反馈"。你现在第三问是 0 分状态。

今晚 15 分钟就能补：找 2–3 位目标用户（同学、规培医生、影像方向研究生都算），做三件事：

- 给一个真实问题（不是"演示一下"，而是"你最近读片时卡在哪"）；
- 让他们自己操作，你只记录，不引导；
- 录一句原话 + 日期 + 你当晚改了什么。

只要有一条"11 月 23 日，XX 说'出处点进去要翻很久'，我们把定位从病例级细化到分区级"，这项就从 4 分变成 8 分。

### 风险三（可低成本修复）：竞品与创新没按模版口径写

模版要的是**四行表**和**三条事实差异**，不是分析文章。仓库里素材齐全（`四条影像问答路线_功能与局限对照.html`、`多版本软件方案.md`），只是没压缩成评委会看的那张表。这件事 1 小时能做完，回报是 3–4 分。

## 五、三样别浪费的真资产

评委一天看 8 个项目，记住的永远是"别人没有的东西"。你有三样：

1. **`unmentioned` 第四态**：公开来源没有逐区描述时，界面明确写"不作推断"，**绝不渲染成 normal**。这是医学影像 AI 最容易被忽略的伦理坑，你把它做成了产品约束。这一条值得单独占一页 PPT。
2. **证据可复核到字段**：每个结论能回链到"病例 id + 分区 + 状态 + coords 坐标 + 许可"和"词条 id + 来源标题 + 链接"。评委问"这数字哪来的"，你能当场打开文件。
3. **明确的"不做"清单**：不做诊断、不做 DICOM、不做病灶分割、不做账号体系。敢写"不做"的团队，通常是真的想清楚了。

### 关键：第 3 件是代码级改造，不是改文案

原代码里 `llm.py` 确实直连 DeepSeek / DashScope，如果只把说明改成"不含推理"，评委打开代码就会当场戳穿。实际做法：

- `ensure_llm()` 增加硬门禁：未设置 `YZ_ENABLE_DIRECT_LLM=1` 时直接返回 `None`，并打印一行明确日志；
- 默认 `mode` 从 `auto` 改为 `agent`，即一次问答只经 `gateway.py` 转发给 DeepWorks 引擎；
- `llm.py` 文件头标注"实验分支，默认关闭，答辩/验收不使用"；
- 启动日志、`/api/agent/capabilities`、`env.example`、`start.sh` 四处口径统一。

实测输出：

```
default_mode       = agent
inference_location = deepworks_engine
direct_llm_enabled = False
[llm] 直连分支未启用（YZ_ENABLE_DIRECT_LLM 未设为 1）：推理仅经 DeepWorks 引擎
```

**这比"我们不含推理"这句话有力得多：评委可以自己跑一遍。**
