## 二、逐项说明

### P0-1 删除传播（墓碑机制）

**改动**
- [classroom-core.js](kb/app/classroom-core.js)：新增 `addTombstone()`；`removeStudent` / `deleteAssignment` / `deleteGroup` / `deletePost` 在物理删除前记录 `{type, id, classId, name, at}`。
- [classroom-sync.js](kb/app/classroom-sync.js)：`mergeTombstones()` 并集墓碑，`applyTombstones()` 先剔除对象再合并；学生/作业/小组删除会级联清理答题与帖子。
- [classroom_server.py](kb/server/classroom_server.py)：`_merge_tombstones()` + `_apply_tombstones()`，服务端持久化墓碑，pull 时不会再复活。

**验收新增**
- API 层：合并含学生/答题的快照 → 带墓碑合并 → 快照为空，墓碑保留。
- 前端层：页面里加学生 → 删除 → 等待推送 → 服务端查不到该学生。

### P0-2 同步服务鉴权

**改动**
- `--token` / `YZ_SYNC_TOKEN`：`/api/snapshot`、`/api/merge`、`/api/reset` 全部校验 `X-Sync-Token`（或 `?token=`）。
- `/api/reset` 默认 403，必须 `--allow-reset` 或 `YZ_ALLOW_RESET=1`。
- CORS 支持 `--allow-origin`，默认 `*` 保持课堂跨域可用，正式部署建议指定站点。
- 启动时打印口令/重置/CORS 状态；非本机监听且无口令时告警。

**验收新增**：探活 200、无口令 401、错口令 401、正确口令 200、reset 默认 403。

### P0-3 模型交叉检验口径

**改动**
- [build_model_probe.py](kb/scripts/build_model_probe.py)：新增 `eligibility()`，排除 `chest_lat` 与标题含“解剖标注”的病例；主阈值 0.6；输出 0.5/0.6/0.7/0.8 的 `thresholds` 敏感性；支持 `--recompute` 在无 torch 环境重算。
- [run_eval.py](kb/scripts/run_eval.py)：模型汇总改用 `eligible` 口径。
- [eval.html](kb/app/eval.html)：显示“16 / 21 例”、排除说明与阈值敏感性。

**前后对比**

| 指标 | 修复前 | 修复后 |
| --- | --- | --- |
| 统计病例 | 21（含侧位/标注图） | 16（排除 5 例） |
| 主阈值 | 0.5 | 0.6 |
| 严格一致 | 61.9%（13/21） | 68.75%（11/16） |
| 冲突 | 6（全是正常片弱信号） | 0 |
| 阈值敏感性 | 无 | 0.5→81% · 0.6→69% · 0.7→56% |

> 数字变化不是“调高分数”：排除的是模型不适用的侧位片与解剖标注图，同时把阈值敏感性公开，避免单点结论。

### P1-1 评测脚本对齐

**改动**
- 删除 [run_eval.py](kb/scripts/run_eval.py) 中第二次 `parse_region` 定义（会把“左肺中野”解析成“中”）。
- 评测用例新增 `expect_zone` 校验，并加入两条能真正区分左右侧的问法：“左侧中段”“左侧下段”。
- 验证：用旧的错误实现跑这两条会落到 RML/RLL，新实现落到 LML/LLL。

### P1-2 无原文锚点

**改动**
- [ask.html](kb/app/ask.html)：`citation` 为空且 `kind === "zone"` 时，显示“本条无原文锚点……请以影像区域（E1）为准，不要补造出处”。
- [README.md](README.md)：改为“尽量给两条引用链，没有原文时明确标注”，并写明 40 条的分布。

### P1-3 备课包 E1/L1

**改动**
- [classroom.js](kb/app/classroom.js)：证据锚点输出 `E1：CASE-xxx / 分区（zone_id）`、`L1：来源标题 URL`；正常例输出 `E1：全部教学分区未见明确异常`；无来源时写“本病例暂无已登记来源”。

### P1-4 双源对照口径

**改动**
- [build_dual_source.py](kb/scripts/build_dual_source.py)：summary 增加 `coverage_cases`（14）、`no_report`（7 例）、`coverage_note`，明确均值分母。
- 页面原有的空页提示保留：无报告/无指南时显示边界说明，不做外推。

### P1-5 推送队列

### P1-6 定位题覆盖

**改动**
- [build_drill_bank.py](kb/scripts/build_drill_bank.py)：正常例新增 `build_localize_normal()`，正确项为“未见明确异常分区”；侧位片只有 3 个分区时用同一选项补足第 4 项。
- 结果：`localize 21 / 21` 例，答案越界 0。

## 五、遗留与建议

1. **旧客户端兼容**：不带 `tombstones` 的旧页面仍不会传播删除；升级后首次拉取会补上墓碑。课堂现场建议统一刷新一次。
2. **模型探针未重新推理**：本次用 `--recompute` 重算判定，top-5 概率仍是原推理结果；如需更新分数，在 `.venv` 下重跑 `build_model_probe.py`。
3. **墓碑无限增长**：课堂规模下可忽略；长期使用可加“90 天清理”策略。
4. **CORS 默认 `*`**：口令已保护数据，但正式部署仍建议 `--allow-origin http://站点地址`。
5. **P2 之外的遗留**：评测页仍把 dev+holdout+final 合并展示 69/69（已在页面注明“都在调参中查看过”）；如需更严谨，可首屏只放 final。
