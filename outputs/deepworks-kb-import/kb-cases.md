# 公开影像对照（部位 → 病症两级归类）

> 全部来自 Wikimedia Commons 公开许可素材，已逐张核验无患者标识。
> 一级为解剖部位，二级为病症/征象族；同一分类按影像表现或公开描述归并，不代表同一疾病。

## 一级：胸部（18 张）

> 肺、胸膜、纵隔与胸壁；含正常胸部与成像条件对照。

### 二级：肺部实变与气腔影（5 张）

> 以肺野密度增高、实变或气腔影为共同表现的公开影像，用于对照病变分布与空气支气管征。
> 归类依据：来源公开描述含 pneumonia / consolidation / air-space opacity / atelectasis 等关键词，或图中自带标注。
> 使用提醒：同一组内病因不同，仅按影像表现归类，不代表同一疾病。
