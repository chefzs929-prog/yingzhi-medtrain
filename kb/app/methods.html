非诊断用途仅供医学影像教学与研究

方法与边界

RadioCheck 是一个胸片（CR 胸片，正位 / 侧位）阅片教学网站。它把「影像上的位置」和「文献里的原文」并排给你看，但不做诊断。

一、只做胸片专项范围

产品当前只覆盖 CR 胸片正位 / 侧位，不做胸部 CT、乳腺 MG、腰椎 MRI、超声等其他影像。原因很直接：分区模板、逐区标注、征象词条和指南条款都要逐条人工校对，只有胸片这一条线做到了「每个分区都有出处」。

不是胸片的影像，我们不会硬套胸片分区。比如乳腺 MG、腰椎 MRI、头颅 CT，套上胸片或头颅模板会得到看似专业、实际错误的分区结论，这比直接说「不支持」更糟。

二、双引用规则

  • 影像侧：分区 id + bbox + 该分区的来源（人工标注 / 模板推断）。
  • 文献侧：指南条款或征象词条的原文段落 + 出处链接。
  • 两侧缺一，就不输出结论；宁可拒答，也不拼一个只有一半出处的答案。

三、上传影像怎么处理

  • 图片只在当前浏览器内存里显示，不上传服务器、不落盘；请勿上传真实患者影像。
  • 先做文件指纹匹配：命中库内病例，直接打开人工标注版本。
  • 未命中时，走「视觉识别 → 胸片模板定位 → 双引用」：给出模板分区和该区候选征象词条，并明确标注模板推断、非人工标注。
  • 没有视觉模型时，按胸片默认模板（CR / 胸部 / PA）定位，并提示「如果这张不是胸片，请勿使用该分区结果」。

四、其他影像：我们为什么不做，以及未来怎么做

反思。早期版本曾把乳腺 MG、腰椎 MRI 也套进分区模板，出现过「乳腺片显示四个胸片分区」「腰椎 MRI 套头颅分区」的错配。根因不是模型不够强，而是模板匹配缺少「检查类型 / 部位 / 投照位」的硬门控，且没有把「不支持」当成一个正式状态。

现在。上传影像先识别检查类型与部位；不是胸片就明确返回「本产品是胸片专项，暂不支持」，并保留手动分区作为解剖定位的降级手段，不生成征象结论。

未来拓展方向。

  • 多部位模板库：按 modality + body_part + view 建立独立模板，每个模板单独验收，不复用胸片几何。
  • 标注成本前置：先确认每个部位能拿到足量公开、可授权的教学影像，再决定是否开这条线。
  • 质控与拒答：新部位上线前，必须通过「模态错配拒答集」，确保非目标影像不会被硬套模板。
  • 能力边界外显：健康检查与页面都如实标注当前支持的检查类型，不用「多模态」这类模糊说法掩盖覆盖不足。

五、数据与声明

  • 影像来自公开教学数据集，逐例标注许可与作者；不收录真实患者隐私影像。
  • 文献侧引用指南条款与征象词条原文，保留出处链接与段落定位。
  • 本产品不提供诊断、分期、治疗或预后建议，不替代临床决策。
