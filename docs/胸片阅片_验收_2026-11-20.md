## 2. 数据规则自检覆盖

| 规则 | 说明 |
| --- | --- |
| 队列规模 | CR 胸部 23 例；21 例启用；2 例多图/双幅拼接移出（CASE-019、CASE-201） |
| 分区数量 | PA 每例 8 区；LAT 每例 3 区 |
| 状态合法 | 只允许 `abnormal / normal / unmentioned / limited` |
| 文本非空 | 每个分区都有独立文本 |
| 异常区 ≠ 未提及区 | 同一病例内，异常文本与未提及文本不能相同 |
| 侧别正确 | PA 右侧区 `patient_side=right`，左侧区 `left` |
| 出处齐全 | 每例有来源页、许可、SHA-256 |
| 征象可查 | 每例挂的 `SIGN-xxx` 都能在 `sign_index` 找到 |
| 定点规则 | CASE-001 全正常；CASE-006 右肺中野/下野异常、右肺上野未提及；CASE-036 右侧三区异常、左侧三区未提及；CASE-003 有判读受限区 |
| 不误挂指南 | 数据集不出现 guideline 字段，避免把 Lung-RADS 等 CT 条款挂到胸片 |

## 4. 现场演示路径（5 步）

1. 打开 `read/clinic.html`，左侧选 `CASE-001 正常后前位胸片`；
2. 点“右肺上野”→ 右栏显示“未见异常”+ 解剖边界 + 依据；
3. 切 `CASE-006 大叶性肺炎`→ 右肺中野/下野琥珀色，右肺上野与其他分区灰虚线“来源未提及”；
4. 切 `CASE-036 气胸`→ 右侧三区异常、左侧三区未提及；问“有没有气胸？”→ 定位到右肺三区，附征象词条与来源；
5. 点“生成阅片记录”→ 展示系统所见、分区所见、出处、非诊断声明，复制/下载。

## 5. 仍存在的边界

| 边界 | 现状 | 处理 |
| --- | --- | --- |
| 非胸片病例 | 仍在 120 例总库里，但不在胸片队列 | 页面与 README 明确“当前版本聚焦胸片” |
| 陌生影像上传 | 静态版只做 SHA-256 精确匹配 | 匹配不上明确拒绝；本地服务可用时再接视觉模型 |
| Agent 问答 | 静态页用确定性规则，不调 8800 | 不把静态兜底伪装成模型输出；DeepWorks 接入见 `docs/Agent接入指南.md` |
| 分区框精度 | 教学分区，按解剖比例近似 | 界面固定标注“不是病灶分割”；未做像素级配准 |
| 诊断准确率 | 未做影像诊断准确率评测 | 本页只做“公开来源 → 分区 → 出处”的可核对复述 |
| 内容审核 | 逐区文本由本库结构化校正表生成（AI 辅助） | 正式教学前须由医学人员逐条审核签字 |
