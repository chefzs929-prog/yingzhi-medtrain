# 影像审核报告（2026-11-20）

## 审核范围与方法

- 范围：`kb/images/` 下 209 个图片文件，以及 `cases.jsonl` 中 200 条病例记录。
- 方法：
  1. 逐张目视：195 张在册影像生成缩略图全览，关键图放大复核；
  2. 文件哈希去重：MD5 分组，识别同一图被多个病例引用；
  3. 图文比对：图像内容与 `title / body_part / modality / pose_class` 逐条核对；
  4. 隐私检查：查看图像四角，识别姓名缩写、检查号、年龄、检查日期；
  5. 构建后验证：120 张图全部加载、自检 8/8、分区点击抽查。

## 已知局限（诚实边界）

1. **分区是解剖区域，不是病灶勾画。** 分区 bbox 按部位模板划分（如右肺上野、中段椎体层面），用于"点哪看哪"，不表示病灶边界。440 个分区中，定位自检命中 71.4%、跨区 24.5%、未命中 4.1%（`outputs/medtrain/locate_selfcheck.md`）。
2. **结论是影像描述级，不是诊断。** 每条结论写的是"该区可见什么"，并统一附"不构成诊断意见"声明；`audit.human_review` 全部为 `pending`，尚未经执业医师逐条签字。
3. **文献对照只覆盖 33 条。** 甲状腺、乳腺、肝、肺结节/正常胸片挂了对应指南条款；其余 407 条标为 `imaging_only`，界面显示"仅影像描述"，不再用模板征象硬凑文献。
4. **部分图像质量一般。** 少数为教学标注版（箭头、文字、彩色覆盖）或 512 px 级导出图，已保留原样并在标题中注明"标注版"；不满足高分辨率出版要求。
5. **补充影像的来源描述为英文原页。** 中文标题是按图像内容与来源描述改写的，未逐条请放射科医师复核。
