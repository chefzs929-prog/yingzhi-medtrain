# 反思与未来拓展方向：为什么只做胸片

## 1. 这篇文档要解决什么

产品当前只做 **CR 胸片**（正位 / 侧位），**不做**胸部 CT、乳腺 MG、腰椎 MRI、超声等其他影像。这不是能力不足的托词，而是主动收缩：分区模板、逐区标注、征象词条和指南条款都需要逐条人工校对，只有胸片这一条线做到了「每个分区都有出处」。

早期版本曾尝试「什么影像都能上传、都能套模板」，结果出现了明显的错配，必须记录下来。

## 2. 已经发生的错配（真实截图）

- **乳腺 MG 套上胸片分区**：上传乳腺 X 线片，页面显示四个胸片分区框。
- **腰椎 MRI 套上头颅分区**：上传腰椎 MRI，页面显示「头颅 CCO」与「周边带 REG-105-EDGE」。
- **未填问题直接拒答**：选中病例后未输入问题，页面直接显示拒答与「双引用覆盖全缺失」，用户不知道是「没问」还是「不会答」。

这些错配的共同点：系统把「找不到合适模板」当成了「找一个差不多的模板套上」，而不是一个正式的「不支持」状态。

## 3. 根因

1. **模板匹配缺少硬门控**：只按部位或模态的模糊相似度匹配，任意一项命中就返回模板，没有要求 modality + body_part + view 同时成立。
2. **缺少「不支持」状态**：定位结果只有「命中 / 未覆盖」，没有「检查类型不在支持范围」这一档。
3. **前端上传即拒答或硬套**：上传路径没有接视觉定位，要么直接拒答，要么退回手动分区；两条路都没有把「这是什么检查」说清楚。
4. **双引用状态不可见**：拒答时没有区分「缺影像侧」「缺文献侧」「没问问题」，用户无法判断下一步。

## 4. 现在怎么改的

- **后端硬门控（已落地）**：`yingzhi/serve/atlas.py` 的 `chest_gate()` 把请求分成三态 —— `chest`（CR/DX/XR/DR/RF + 胸部）、`not_chest`（其他模态或部位，直接拒绝）、`unknown`（没给检查信息，不猜）。`match()` 增加 `allow_ids` 白名单，且部位明确不符时直接排除候选，避免「头颅 CR 侧位」靠模态分命中「胸片侧位四区」。非胸片返回 `reason: unsupported_modality` + `scope: chest_xray_only`，`/api/vision/atlases` 也只暴露 2 个胸片模板。
- **正式的不支持状态**：页面明确显示「本产品是胸片专项，暂不支持这张影像」，并说明识别到的检查类型与部位。
- **模板推断必须标注**：胸片模板定位显示「模板推断、非人工标注」，并提示演示或教学前须人工复核。
- **无视觉模型时不猜**：后端标记 `assumed_chest: true`，前端不输出分区结论、不画分区框，只显示「未确认影像类型 · 暂不做分区判断」和一个显式确认按钮；用户点「我确认这是胸部 X 线片，继续定位」后才按胸片模板定位。离线时胸片与非胸片不会再得到同样的分区输出。
- **双引用缺一不输出**：上传影像没有库内分区结论，就不生成「分区结论」引用；文献侧只给该分区的候选征象词条，并标注「非本片所见」。
- **入口可见**：站内「方法与边界」页（`read/methods.html`）写明范围、双引用规则与未来拓展。

## 5. 为什么先不做其他影像

| 维度 | 胸片 | 乳腺 MG | 腰椎 MRI | 头颅 CT |
| --- | --- | --- | --- | --- |
| 公开可授权教学影像 | 充足 | 较少 | 较少 | 中等 |
| 分区/模板可复用性 | 高 | 低（需独立几何） | 低（需独立几何） | 中 |
| 逐区标注成本 | 已投入 | 需从零 | 需从零 | 需从零 |
| 错配风险 | 低 | 高 | 高 | 中 |

结论：在没有足量公开影像和逐区标注之前，开新部位只会放大错配风险。先把胸片做到「每个分区都有出处」，再按部位逐条开线。

## 6. 未来拓展方向（按阶段）

### 阶段一：胸部 CT 对照（最近）

- 复用现有胸部解剖分区，但为 CT 轴位单独建模板，不复用胸片几何。
- 验收门槛：CT 轴位切片的分区命中率、跨层一致性、非胸部 CT 的拒答率。

### 阶段二：骨关节 X 线

- 按部位（肩 / 膝 / 踝）分别建模板，每个模板单独验收。
- 验收门槛：左右侧识别、投照位识别、骨折征象词条的文献侧覆盖率。

### 阶段三：乳腺 MG

- 需要独立的 MLO / CC 模板与乳腺分区体系，不能复用胸片几何。
- 验收门槛：MLO/CC 识别、象限定位、钙化/肿块词条的出处完整性。

### 阶段四：其他模态（MRI / 超声）

- 先解决「同一部位多序列」的模板选择问题，再谈分区。
- 在拿到足量公开、可授权的教学影像之前，不进入开发。

## 7. 每个新部位上线前的硬门槛

1. **模态门控**：非目标影像必须返回「不支持」，不能命中任何模板。
2. **错配拒答集**：至少覆盖「乳腺 MG / 腰椎 MRI / 头颅 CT / 腹部 CT」四类非目标影像。
3. **双引用完整**：影像侧（分区 + bbox + 来源）与文献侧（原文 + 出处）同时可用。
4. **人工复核标注**：模板推断必须与人工标注区分显示。
5. **健康检查如实**：`/api/health` 与「方法与边界」页同步更新支持范围。

## 8. 明确不做的事

- 不把「多模态」当成卖点：当前只支持胸片，就只写胸片。
- 不用其他部位的模板「凑一个分区」：宁可拒答。
- 不把模板推断说成人工标注。
- 不在没有文献出处的情况下输出征象结论。
