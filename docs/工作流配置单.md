# DeepWorks 平台链路配置单（技能 + 自动化任务）

> **三条链路要分开看，不能互相冒充**
> - 本地五步编排（`yingzhi/serve/workflow.py`）：已落地，每次 `/api/ask` 真实执行，`/api/health` 报 `real_workflow=true`，完整证据在 `workflow.json`；
> - 平台技能链路（本单第 1 部分）：已落地，`radhearing-ask` 技能在本项目会话内可调用；
> - 平台自动化任务（本单第 2 部分）：已落地，用于每日回归与留证。
>
> **平台事实（2026-11-24 实测）**：DeepWorks 桌面端个人版当前**没有可视化工作流编排画布**，扩展只暴露 `deepworks-automation`。本单按“技能 + 自动化任务”配置，不再要求创建 3 节点画布。

## 0. 配置前 30 秒自检

在项目根目录跑这两条，确认技能脚本本身是通的：

```bash
python3 .opencode/skills/radhearing-ask/scripts/ask.py "右肺中野有什么问题" --case CASE-006
python3 .opencode/skills/radhearing-ask/scripts/ask.py "这张片子是不是肺癌" --case CASE-006
```

- 第一条应出现：`右肺中野（RML）`、`left=0.06`、`GL-PNE-02`、`第 68 字起`、`f25ddcf0`
- 第二条应出现：`不能回答`、`诊断结论`、替代问法

两条都对，再进平台。脚本不通，平台链路一定不通。

## 1. 平台技能链路

### 1.1 基本信息

| 字段 | 填这个 |
| --- | --- |
| 技能名 | `radhearing-ask` |
| 技能位置 | `.opencode/skills/radhearing-ask/SKILL.md` |
| 触发方式 | 会话命令 `/radhearing <问题>`，或自然语言点名技能 |
| 作用域 | 本项目会话（`黑客松`） |
| 超时 | 60 秒 |

### 1.2 调用示例

```text
/radhearing 右肺中野有什么问题
```

或：

```text
用 radhearing-ask 技能回答：这张片子是不是肺癌，病例 CASE-006
```

### 1.3 验收：三条输入，缺一不可

| # | 输入 | 必须看到 | 看不到说明什么 |
| --- | --- | --- | --- |
| 1 | `右肺中野有什么问题`（CASE-006） | `RML`、`left=0.06`、`GL-PNE-02`、`第 68 字起`、`f25ddcf0` | 没有 `GL-PNE-02` 或 `第 68 字起` = 模型在编，技能没被执行 |
| 2 | `这张片子是不是肺癌` | `不能回答`、`诊断结论`、替代问法 | 拒答分支没生效 |
| 3 | `这张 CT 有没有脑出血` | `不能回答`、`超出影像模态` | 范围边界没生效 |

第 1 条是防伪关键：只要出现 `GL-PNE-02` 和 `第 68 字起`，就能证明回答来自库内脚本，不是模型生成。

## 2. 平台自动化任务

### 2.1 任务字段

| 字段 | 填这个 |
| --- | --- |
| 名称 | `影知 · 平台链路回归` |
| 频率 | 每天 09:00（或手动触发） |
| 执行方式 | 共享会话（默认） |
| 任务内容 | 运行三条验收命令，逐条比对锚点；任一缺失即 FAIL |

### 2.2 任务内容

```text
在 /Users/fz/Desktop/黑客松 下依次执行：
1) python3 .opencode/skills/radhearing-ask/scripts/ask.py "右肺中野有什么问题" --case CASE-006
2) python3 .opencode/skills/radhearing-ask/scripts/ask.py "这张片子是不是肺癌" --case CASE-006
3) python3 .opencode/skills/radhearing-ask/scripts/ask.py "这张 CT 有没有脑出血"

判定：
- 第 1 条必须同时出现 GL-PNE-02、第 68 字起、left=0.06、f25ddcf0；
- 第 2 条必须出现“不能回答”和“诊断结论”；
- 第 3 条必须出现“不能回答”和“超出影像模态”。
全部满足输出 PASS；否则输出 FAIL + 缺失项原文。
```

> 仓库里已有一条同类任务：`automation-chat-edbb0aed412f38bc4179d49f`（影知 · 影像双引用问答回归）。可复用，不必重复建。

### 2.3 验收

- 任务存在且处于启用状态；
- 最近一次运行结果为 PASS；
- 运行记录里能看到三条命令的输出摘要。

## 4. 常见失败与处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 技能列表搜不到 `radhearing-ask` | 项目技能未加载 | 确认 `.opencode/skills/radhearing-ask/SKILL.md` 存在，重开会话 |
| 输出通顺但没有 `GL-PNE-02` | 模型凭记忆答 | 用 `/radhearing` 命令重跑；确认技能被调用 |
| 脚本报错找不到病例 | `case_id` 为空且问题里没有实体 | 固定填 `--case CASE-006` |
| 拒答变成“建议就医” | 回答被模型自由发挥 | 明确要求保留脚本的 refusal 原文 |
| 自动化任务失败 | 脚本路径/病例号变动 | 先本地跑第 0 步两条命令，再改任务内容 |
