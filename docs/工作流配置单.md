# DeepWorks 工作流配置单

> 用途：在 DeepWorks 界面「工作流」里照着填，3 步，约 2 分钟。
> 为什么不能由 Agent 代建：工作流是界面可视化编排，没有开放工具/API/CLI，且不存为本地文件。
> 填完后请截一张「工作流已保存」的图，放进说明书。

---

## 工作流基本信息

| 字段 | 填这个 |
| --- | --- |
| 名称 | 影知 · 影像双引用问答 |
| 描述 | 输入胸片问题，输出带区域锚点与文献锚点的回答；无证据时拒答 |
| 触发 | 手动 / 对话输入 |

---

## 第 1 步：输入

| 字段 | 填这个 |
| --- | --- |
| 节点类型 | 输入 / 开始 |
| 变量名 | `question` |
| 类型 | 文本 |
| 示例值 | `右肺中野有什么问题` |

可选第二输入（如果界面支持多输入）：

| 变量名 | 类型 | 说明 |
| --- | --- | --- |
| `case_id` | 文本，可空 | 留空则自动选片；填 `CASE-006` 可固定演示 |

---

## 第 2 步：技能调用

| 字段 | 填这个 |
| --- | --- |
| 节点类型 | 技能 / Agent 调用 |
| 技能名 | `radhearing-ask` |
| 入参 | `question = {{question}}` |
| 超时 | 60 秒 |

如果界面的技能节点需要一段提示词，粘贴这段：

```
按 radhearing-ask 技能处理问题：{{question}}

必须做到：
1. 先定位影像区域（返回分区编号与解剖名），再匹配征象，最后检索指南条款
2. 回答必须同时给出「区域证据」和「文献原文（≥10 字连续片段）」
3. 任一侧缺失则按拒答分类拒绝，并给出替代问法
4. 涉及诊断结论、分期、治疗、预后时直接拒绝
```

---

## 第 3 步：输出

| 字段 | 填这个 |
| --- | --- |
| 节点类型 | 输出 / 结束 |
| 输出变量 | `answer` |
| 格式 | Markdown |

输出结构约定（界面若支持模板，粘贴这个）：

```
### 区域
{{region_name}}（{{interval}}，置信度 {{confidence}}）

### 影像证据
{{image_evidence}}

### 文献证据
「{{citation_text}}」— {{citation_source}}

### 边界
{{refusal_reason}}
```

---

## 建完必须自测这两条（截图存证）

| 输入 | 期望 | 不通过说明什么 |
| --- | --- | --- |
| `右肺中野有什么问题` | 返回 RML/右肺中野 + 至少 1 条征象 + 1 条文献原文 | 技能未连通，检查技能名是否 `radhearing-ask` |
| `这张片子是不是肺癌` | 明确拒答，说明"不能下诊断"，并给替代问法 | 拒答分支未生效，检查第 2 步提示词第 4 条 |

两条都通过，这一项就算完成。

## 如果界面没有「工作流」入口

退而求其次，用「自动化任务」也能证明编排能力：

- 名称：影知每日自检
- 频率：每天 09:00
- 内容：运行 `python3 medtrain/build.py` 并报告 `site_check` 结果

但**优先级低于真正的 3 步工作流**——评委看的是"问答链路是否在平台内跑通"，不是定时任务。
