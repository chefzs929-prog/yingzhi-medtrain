# 多模态知识库问答 · 核心功能说明

> 版本：v1.0 · 2026-11-17
> 对应实现：`medtrain/app/ask.js`、`medtrain/app/ask.css`，构建产物在 `outputs/medtrain/`
> 入口：`app.html#/ask`（应用默认视图）、产品首页 `index.html` 首屏

## 0. 一句话

**影像给区域，文献给段落；不确定就明说。**
输入一张影像与一段报告/指南文字，回答必须同时挂上「图上哪一块」与「哪份文献哪一段」；
任一侧缺失就降级或拒答，越出教学范围直接拒答，所有输出固定声明非诊断用途。

## 1. 为什么把它做成核心

原平台以「基础知识问答 / 临床知识迁移 / 真实病例演练 / 真实场景应用」四链条为骨架，
能力分散在多个页面。赛题要求的是一个可当场验证的多模态问答闭环，因此把它提为默认首屏：

| 赛题要求 | 页面上的对应 |
| --- | --- |
| 输入影像与报告/指南文档 | 左栏：120 例已标注病例或上传影像；报告文本框、`.txt/.md` 上传、47 条指南条款可选 |
| 回答同时引用影像区域与文献段落 | 右栏：影像引用卡（分区 id + bbox + atlas + 标注人）与文献引用卡（原文 + 版本 + 定位 + hash/官方入口） |
| 对不确定诚实拒答 | 三态判定：可答 / 部分可答 / 拒答；每种都给出具体原因 |
| 声明非诊断用途 | 页脚、回答底部、左侧栏脚注、产品首页四处固定声明 |

## 2. 页面结构

```
┌ 01 输入 ─────────┬ 02 影像与分区 ────────┬ 03 回答与双引用 ──────┐
│ 病例 / 上传影像   │ 影像 + 人工分区框      │ 状态：可答/降级/拒答   │
│ 报告 / 指南文本   │ 点框选中分区           │ 回答原文（只复述库内） │
│ 指定条款（可选）  │ 分区卡：atlas/bbox/侧别│ 影像引用卡 + 文献引用卡 │
│ 问题 + 6 个预置   │ 隐藏分区开关           │ 覆盖检查 / 依据链      │
└──────────────────┴───────────────────────┴───────────────────────┘
页脚：非诊断声明 + 诚实性自检（8 项，可当场重跑）
```

窄屏（≤1200px）自动变为两栏，≤900px 单列堆叠；移动端底部导航保留「问答」入口。

## 3. 判定规则

### 3.1 检索顺序

1. **输入归一化**：报告 + 问题合并；`有没有` 等提问句式不当作否定。
2. **征象识别**：60 条征象的名称、别名、英文名与人工同义词表；同一分句出现「未见 / 未发现 / 无明确」时按阴性处理，不产生阳性征象。
3. **病例选择**：默认「自动匹配」；按部位族、模态、命中的征象种类计分，不按结论条数累加。用户也可锁定某个病例。
4. **分区选择**：分区名文字匹配 + 征象重合 + 该分区是否有指南条款；文字无线索时用「结论挂在哪个分区」反推，多个分区并列则不猜。
   若该病例存在同一征象的**人工图文锚点**（`kb/data/sign_links.jsonl`），优先用锚点自己的 bbox 与说明，并把分区对齐到与锚点重叠最大的区域。
5. **结论选择**：同一分区内按征象重合、是否带指南条款、分类词（TR4 / BI-RADS 4 / 类别 1 等）匹配度排序。
   **引用完整性门禁**：`cite_status = broken` 或摘录 hash 与库内原文不一致的结论一律排除，不进入回答。
6. **文献选择**：47 条指南条款按部位族、分类词、关键词、征象名打分；得分相同视为「条款并列」；没有指南条款时降级到该结论挂的征象词条摘录。

### 3.2 三种状态

| 状态 | 条件 | 处理 |
| --- | --- | --- |
| 可答 `answer` | 影像输入 + 分区 + 分区结论 + 指南条款，且无并列/缺条件/侧别冲突 | 输出回答与两张引用卡 |
| 部分可答 `partial` | 文献侧降级为词条释义；条款并列；缺尺寸；征象并列；左右侧冲突 | 仍输出，但逐条列出降级原因；文献卡标注「降级：非指南条款」 |
| 拒答 `refuse` | 空输入；未命中征象；缺分区；缺结论；缺文献；上传影像未标注；诊断/治疗越界 | 不输出结论；给出原因、已检索到的线索与可改问法 |

### 3.3 拒答的六种原因

| reason | 触发 | 文案要点 |
| --- | --- | --- |
| `no-signal` | 输入为空或未命中 60 条征象 | 不猜测；建议换库内词条或点选分区 |
| `no-region` | 上传影像未标注；或文字无线索且多个分区并列 | 说明缺 bbox / 分区 id，按双引用规则不输出 |
| `no-claim` | 分区在库内没有结论 | 建议换已标注分区 |
| `no-doc` | 影像侧命中但文献侧无条款也无词条摘录 | 建议补充分类信息 |
| `scope` | 出现诊断、良恶性、手术、用药、预后等意图 | 说明只做表现与条款对照 |
| `no-case` | 自动匹配失败 | 兜底到首个病例，不编造 |

## 4. 引用长什么样

**影像引用**

```
REG-001-RML · 右肺中野
ATLAS-CHEST-PA-6 · bbox [0.12, 0.35, 0.36, 0.23]
图像左侧 = 患者右侧 · human 标注 · 可回查
```

- 分区框是**人工标注的解剖区**，不是病灶分割；点框只改变「看哪儿」，不改变结论。
- 有图文锚点时，引用卡显示 `ANCHOR-SL-xxx` 与锚点说明（如 SL-005 的磨玻璃影 CT 框），并同时给出对齐后的分区 id。
- 中央/非侧别分区（如甲状腺中央区）不套用左右侧规则，界面显式写出。

**文献引用**

```
GL-TIRADS-03 · ACR TI-RADS · 2017
TR4 · 穿刺与随访
“TR4 类结节最大径达到约 1.5 cm 时可考虑穿刺；1.0—1.5 cm 以随访为主。”
指南条款 · 官方入口
```

- 条款原文来自 `kb/data/guidelines.jsonl`，只摘录，不转述为建议。
- 结论自带的征象词条摘录带 8 位 hash，可回查；界面明确标为「降级：非指南条款」。
- 库内保留 1 条失败样例 `CLM-007`（模型把 TR4 阈值从 1.5 cm 改写成 1.0 cm）。问答页会拦截它，并在「不确定与降级说明」里写出拦截了哪一条；覆盖检查显示「引用校验：通过 · 拦截 1 条」。

## 5. 诚实性自检

页面内「诚实性自检」固定 8 个输入，全部在本地规则引擎上跑，不依赖后端：

| # | 输入 | 期望 |
| --- | --- | --- |
| 1 | 正常胸片 + 「右肺中野有没有结节？」 | 可答 + 指南条款 |
| 2 | 甲状腺 TR4 + 1.6 cm | 可答 + TR4 条款 + 拦截 CLM-007 |
| 3 | 空输入 | 拒答 / no-signal |
| 4 | 「这是不是肺癌？要不要手术？」 | 拒答 / scope |
| 5 | 上传影像（未标注） | 拒答 / no-region |
| 6 | 头颅 + 脑膜强化 | 部分可答 / 文献降级 |
| 7 | 磨玻璃影但缺尺寸 | 部分可答 / 条款并列 |
| 8 | 磨玻璃影 + 最大径 7 mm | 可答 / ≥6 mm 条款 |

构建后运行：

```bash
cd outputs/medtrain && python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/app.html#/ask
# 或运行完整验收
python3 medtrain/tests/ui_check.py   # 118 项，含问答页 21 项
```

## 6. 能力边界（写进界面，不只写在文档）

- **不做**病灶检测、分割、自动测量；分区框是解剖区，不是病灶轮廓。
- **不做**诊断、良恶性判断、治疗建议、预后判断；相关提问直接拒答。
- **不做**自由生成：回答只复述库内结论与条款原文，避免模型编造引用。
- **不做**上传影像的自动配准：未标注就没有 bbox，宁可拒答。
- 当前检索是词条/别名/关键词匹配，不是语义向量检索；未命中时拒答，不用相似词硬凑。
