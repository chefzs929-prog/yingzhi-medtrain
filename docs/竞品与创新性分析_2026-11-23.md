# 竞品对照与创新性逐条分析 · RadioCheck v10.1

> 对象：RadioCheck（影知）｜赛道 B 医学影像知识问答
> 目的：为项目说明书的「竞品分析 10 分 + 创新性分析 10 分」提供可查事实与可直接改写的话术
> 口径：产品能力以 `outputs/medtrain/` 发布数据为准；竞品事实来自公开资料，检索日期 2026-11-23
> 原则：只写能指到文件或来源的差异；不写“全球首个”“唯一”等无法证明的形容词

---

## 0. 一页结论

**选这两个竞品，不是为了证明“我们更强”，而是为了把 RadioCheck 的位置卡在两者中间：**

- **Radiopaedia** 代表“内容型教学”的天花板：病例多、文章多、国际权威，但答案是**文章级/病例级**，不绑定分区，也没有中文课堂。
- **推想 InferRead DR Chest** 代表“AI 筛查”的天花板：有合规证、有热图、有结构化报告，但输出是**概率与位置**，不解释文献依据，也不做教学。
- **RadioCheck** 做的是第三件事：把“读片的证据”下沉到**教学分区级**，让每条答案同时带影像锚点（E1）与文献锚点（L1），并用 `unmentioned` 第四态把“来源没写到”与“正常”分开。

**八条创新点里，真正能站住的是三条：**

1. `unmentioned` 第四态（58/153 个分区，37.9%，不是 UI 装饰）；
2. 分区级双引用（E1 + L1，可点开原图复核）；
3. 可评分教学闭环（定位 40 / 判读 30 / 征象 30 + 错题 + 学情）。

**两条不要单独讲：** 对比阅片、许可治理。它们是可信度背书，不是创新点。
**一条必须换话术：** “纯静态零后端”容易被评委读成“壳工程”，要写成“站外只读展示层，核心链路在 DeepWorks 内”。

## 1. 竞品选择与事实基线

### 1.1 为什么选这两个，而不是 PACS 或通用大模型

| 候选 | 为什么不用作主竞品 |
| --- | --- |
| 院内 PACS 报告检索 | 是“流程工具”，不是“教学/问答产品”；对比它只能得出“我们也能搜”这种弱差异 |
| 通用多模态大模型（GPT-4V 类） | 不是医学影像教学产品；对比它容易变成“我们更准”的口水战，且无法核实 |
| 医考帮/题库类 | 只覆盖“做题”，不覆盖影像定位与证据链；可作为第三备选，不作为主竞品 |
| **Radiopaedia** | 内容型教学的真实标杆，直接对应“知识库 + 病例 + 自测” |
| **推想 InferRead DR Chest** | 胸片 AI 的真实标杆，直接对应“同一张胸片上的 AI 输出” |

两个竞品一个比“内容与教学”，一个比“AI 与落地”，正好夹住 RadioCheck 的生态位。

### 1.2 竞品 A：Radiopaedia

**是什么**：2005 年上线的放射学协作百科 + 病例库，英文，编辑委员会同行评审，含文章、病例、解剖模块、quiz、课程与 CME。

**可核实事实**：

- 规模：截至 2023 年 12 月，约 **16,719 篇文章 + 56,720 例病例**；公开资料另有“6 万+ 病例、1.6 万+ 文章”的表述。
- 语言：文章内容**仅英文**。
- 商业模式：免费账号可用大部分内容；**All-Access Pass 付费订阅**解锁无广告、结构化报告模板、进阶 quiz、CME 证书等；收入来自广告、课程与付费支持者。
- 许可：大部分内容为 **CC BY-NC-SA**，非商业使用；影像版权归贡献者，按 CC 授权给平台与用户。
- 功能：关键词搜索、按系统/部位/诊断分类、病例多帧浏览、影像标注、quiz 自测、课程、CME。
- 用户：放射科医生、住院医、影像技师、医学生；2020 年调查显示美国 90% 值班影像住院医把它作为一线/二线参考。

**它强在哪**：内容规模、权威性、社区与课程体系；病例是真实临床病例，多模态、多帧。
**它的边界**：答案停留在**文章级/病例级**；病例页有影像与诊断讨论，但不会把“这句话”绑定到“这个分区 bbox + 这条文献条款”；没有中文界面；没有班级、作业、学情；内容是 NC，不能直接再分发进商业教学产品。

> 事实与推断的边界：以上规模/许可/订阅来自公开资料；“不绑定分区 bbox 与条款”是对其公开功能形态的判断，未逐页核验其全部病例页。

### 1.3 竞品 B：推想 InferRead DR Chest

**是什么**：推想医疗的胸片 AI 辅助筛查软件，接收 DICOM 胸片，输出异常概率、热图、病灶位置与结构化报告。

**可核实事实**：

- 输入：DICOM 胸片（PA/AP），兼容不同厂商 X 光机；可离线或在线部署。
- 输出：结核概率、热图、各异常位置、二分类结果、结构化报告；可按需增加结节、骨折、感染、气胸、主动脉钙化、积液、心影增大等检测。
- 性能：公开资料标称处理时间 **5–20 秒**。
- 合规：CE MDR **IIb**；同系列 CT 产品获 NMPA 三类、FDA、CE、PMDA；DR 产品的具体注册证以官方为准。
- 部署：医院内网私有化，PACS/RIS 集成；按 license/SaaS 年费采购；厂商口径覆盖 30+ 国家、1000+ 机构。
- 场景：影像科、体检、基层结核筛查、远程放射；用于辅助诊断/分诊，不单独作诊断依据。

**它强在哪**：合规、工程化、与 PACS 工作流融合、真实临床落地；输出直接进入医生阅片流程。
**它的边界**：输出是**概率、热图、位置**，不是“这条结论来自哪篇文献的哪一条”；不做教学分区、不做课堂、不做作业评分、不做中文问答；采购与集成门槛高。

> 事实与推断的边界：功能/部署/认证来自厂商与公开产品资料；“不做教学/课堂”是按其产品定位与公开功能判断，未见教学模块。

### 1.4 成本口径说明

| 方案 | 成本写法（建议） | 备注 |
| --- | --- | --- |
| Radiopaedia | 个人免费层 + All-Access 订阅；机构另有授权 | 不写具体金额，避免汇率/档位误差 |
| InferRead DR Chest | 院内 license/年费，公开中标案例为数十万元级 | 公开中标价多为 CT 模块，DR Chest 具体报价未公开，写“量级”不写精确价 |
| RadioCheck | 静态站零边际成本；模型调用按 DeepWorks 积分；主要成本是标注人力 | 与竞品不在同一成本结构，不能直接比“谁便宜” |

## 3. 逐条创新性分析

### 3.1 评级方法

- **L1 范式创新**：定义了新的问题或新的交互范式。
- **L2 组合创新**：把已有能力组合到新场景，产生新用法。
- **L3 工程创新**：把已知原则做成可运行、可验证的产品约束。
- **L4 行业标配**：竞品普遍具备，不宜单独讲。

四维打分（1–5）：新颖度、可辩护度（能否用事实挡住质疑）、竞品差距、演示可见度。

### 3.2 八条逐条对照

#### 创新点 1：分区级双引用（E1 影像锚点 + L1 文献锚点）

**项目做法**：学生实验室问答的每条命中给两组证据——E1（病例 id + 分区名 + 状态 + 缩略图黄色区域框 + 许可 + `clinic.html?case=` 链接）与 L1（征象 id + 定义 + 来源标题/链接）；命中指南时另给 G1 条款与适用条件；页面底部给一条可核对的双引用链 `E1 CASE-036 / 右肺上野 → L1 SIGN-008 气胸 → SRC-RADIO`。见 [README.md](../README.md#L76-L87) 与 [学生影像实验室文档](学生影像实验室与互助小组_2026-11-22.md)。

**Radiopaedia**：病例页有影像、诊断、讨论与参考文献；文章有引用。但“答案”不是结构化地绑定到某个分区 bbox + 某条文献条款；检索与阅读停留在文章/病例级。

**InferRead DR Chest**：输出热图、位置、概率与结构化报告；不给文献条款，也不给教学分区。

**事实差异**：把“结论”下沉到**分区级空间锚点 + 文献锚点**，两个锚点都能点开复核；不是“给个链接”，而是“给到字段”。

**评级**：L2 组合创新 + L3 工程实现。新颖度 3.5 / 可辩护 4 / 竞品差距 4 / 演示 5。

**可被质疑处**：Radiopaedia 病例本身有影像标注；“双引用/证据溯源”在医疗 AI 里不是全新概念。
**应对话术**：“我们不是发明了引用，而是把引用做到教学分区级，并且要求两侧同时存在；缺一侧就降级或拒答。”

#### 创新点 2：`unmentioned` 第四态（来源未提及 ≠ 正常）

**项目做法**：153 个教学分区中，`abnormal` 44、`normal` 50、`unmentioned` **58**、`limited` 1；`unmentioned` 占 **37.9%**。界面用灰色虚线并写“不作推断”，代码与评分规则都不把它渲染成 `normal`。见 [README.md](../README.md#L118-L127)。

**Radiopaedia**：病例描述由放射科医生撰写；没有逐区描述时，读者通常默认“没写=正常”，产品不单列“未提及”状态。

**InferRead DR Chest**：输出阴性/概率，是模型判断；不区分“训练标签没标”与“影像正常”。

**事实差异**：把“来源没写到”做成**一等状态**，而不是默认正常；这是认识论层面的差异，不是 UI 差异。

**评级**：L2 概念产品化，**八条里最强**。新颖度 4 / 可辩护 5 / 竞品差距 4.5 / 演示 5。

**可被质疑处**：是不是只是加了一个灰色标签？
**应对话术**：“58/153 个分区真实处于该状态；课堂评分里‘来源未提及’是独立选项；代码层禁止把它渲染成 normal。它改变的是判读结论，不是颜色。”

#### 创新点 3：征象语义层检索（别名/同义词/概念反查）

**项目做法**：知识底座 60 条征象（中英文名、别名、定义、may_see_in、pitfalls、tags）、136 个概念（`sign_ids` 直接挂载 / `related_sign_ids` 关联征象）、47 条指南条款；同义表述（磨玻璃影 / GGO）可召回；概念命中时区分“直接挂载”和“关联征象”，关联不当作原文依据。

**Radiopaedia**：全文搜索 + 分类/系统/征象标签；英文；文章级。
**InferRead DR Chest**：固定病种输出，不提供开放检索。

**事实差异**：中文同义/别名 + 概念→征象反查 + 每条命中带证据卡；检索结果不是“文章列表”，而是“可定位的征象-病例对”。

**评级**：L3 工程创新。新颖度 2.5 / 可辩护 3.5 / 竞品差距 3.5 / 演示 4。

**可被质疑处**：规模只有 60/136/47，规则检索不如 embedding 泛化。
**应对话术**：“规模是下一阶段；当前选择规则检索是为了可解释、零幻觉、可审计。每条命中都能回到 id 与原文，而不是相似度分数。”

#### 创新点 4：库外拒答 + 通识补充禁 id

**项目做法**：`SCOPE_WORDS` 命中治疗/手术/用药/预后/操作即拒答；诊断类问题在缺少“依据/标准/表现/征象/鉴别”等限定词时拒答；四类检索都未命中时写“库内未命中”，通识段以 `【通识补充·非库内证据】` 开头，且**禁止出现任何 SIGN-/CON-/GL- id**；低置信同样拒答。见 `outputs/medtrain/read/student-lab.js`。

**Radiopaedia**：不提供问答，用户自己读文章；没有“拒答”概念。
**InferRead DR Chest**：固定输出，不回答开放问题；没有“库外”概念。

**事实差异**：把“不知道”做成**可展示的答案类型**，并禁止伪引用；不是“模型自觉不编”，而是规则 + 回归测试。

**评级**：L3。新颖度 3 / 可辩护 4.5 / 竞品差距 4 / 演示 4。

**可被质疑处**：通用大模型也能拒答。
**应对话术**：“区别在可验证：6 条越界问句 100% 拒答、3 条正常问句不误拒，且进入回归测试；通识段出现 id 会被判为最严重错误。”

#### 创新点 5：可评分教学闭环（40/30/30）

**项目做法**：教师建班（6 位班级码）→ 布置作业 → 学生逐例完成定位（40）、判读（30）、征象（30）→ 提交即评分 → 解锁分区所见/系统阅片/出处 → 教师看提交率、均分、及格率、逐例得分率与错题 → 低于 80 分进错题本可重做。见 [README.md](../README.md#L58-L70)。

**Radiopaedia**：有 quiz 与 CME，但以个人自测为主；没有班级、作业、学情、错题本。
**InferRead DR Chest**：无教学模块。

**事实差异**：把“证据结构”变成**可评分任务**——定位、判读、征象三题正好对应“空间锚点、状态、文献征象”；评分只对照库内标注，不评价临床诊断。

**评级**：L2 场景创新。新颖度 3.5 / 可辩护 3.5 / 竞品差距 4.5 / 演示 5。

**可被质疑处**：数据只在 `localStorage`，不是真课堂；评分规则简单。
**应对话术**：“当前是单机演示版，边界写清楚；下一步做可选服务端同步，离线模式保留。评分只对照库内标注，不冒充临床能力评估。”

#### 创新点 6：纯静态零后端 + 离线桌面壳

**项目做法**：站外页面纯静态；上传按 SHA-256 精确匹配库内影像，未入库明确拒绝；PWA；macOS WKWebView 原生壳，断网可演示。

**Radiopaedia**：联网 Web，订阅。
**InferRead DR Chest**：院内服务器/客户端，PACS 集成。

**事实差异**：零运维、零账号、可离线；适合课堂、基层与现场演示。**但这不是“没有后端”，而是“站外只读展示层”**。

**评级**：L3 部署创新。新颖度 2.5 / 可辩护 3 / 竞品差距 3 / 演示 5。

**可被质疑处**：纯静态 = 壳工程；无跨设备同步。
**应对话术**：“核心检索、技能编排、Agent 运行在 DeepWorks 内；站外页面只渲染已产出的结构化结果，不发起任何模型调用。现场用 60 秒录屏证明 DeepWorks 内链路。”

#### 创新点 7：对比阅片（并排/擦除/同步缩放）

**项目做法**：任意两例拖到两侧；并排分隔条、叠加擦除、同步缩放/平移；8 组预置鉴别卡；明确声明“不做图像配准，不能据此判断病灶大小”。

**Radiopaedia**：病例多帧 stack；对比需手动开两个页面，无教学擦除工作流。
**InferRead DR Chest**：有前后片对比/随访（厂商资料），但用于诊断随访，不是教学鉴别。

**事实差异**：把“对比”做成教学鉴别工作流，并明确不配准的边界。

**评级**：L3/L4。新颖度 2 / 可辩护 2.5 / 竞品差距 2.5 / 演示 4。

**可被质疑处**：行业常见；不做配准使“擦除”只能比屏幕位置。
**建议**：不单独讲，作为课堂/鉴别链的一环；讲的时候主动说“我们不配准，所以不下大小结论”。

#### 创新点 8：许可与数据治理

**项目做法**：影像仅 CC0/CC BY/CC BY-SA/公有领域；逐张署名；6 张含标识影像遮盖；每例 SHA-256；非诊断声明；来源与许可可查。

**Radiopaedia**：CC BY-NC-SA，不可商业再分发。
**InferRead DR Chest**：医院数据，私有化部署。

**事实差异**：可再分发的教学数据包 + 可复核哈希；适合开源/院校分发。

**评级**：L3。新颖度 2 / 可辩护 4 / 竞品差距 3 / 演示 3。

**建议**：作为可信度背书，不单独作为创新点。

### 3.4 创新性总评

**能站住的三条**：

1. **第四态**：竞品默认“没写=正常”，RadioCheck 把“未提及”做成独立状态，且真实覆盖 37.9% 的分区。这是认识论差异，最容易被记住。
2. **分区级双引用**：竞品到文章/病灶，RadioCheck 到“分区 + 条款”，且可点开原图复核。
3. **可评分教学闭环**：竞品的 quiz 是个人自测，RadioCheck 把证据结构变成定位/判读/征象三题，能布置、能评分、能看学情。

**站不住、但可以当支撑的两条**：

- 征象检索：规模小，规则检索不新鲜；讲“可解释、零幻觉”而不是“更智能”。
- 对比阅片：行业常见；讲“教学鉴别 + 不配准边界”。

**必须换话术的一条**：

- 纯静态：不要说“我们不需要后端”，要说“站外是只读展示层，核心链路在 DeepWorks 内”。否则会被判壳工程。

**一句话主张**：

> 我们不是又做了一个 AI 读片，而是把“读片的证据”做成了可教、可练、可查的结构。

## 5. 可直接用于说明书的成稿

### 5.1 竞品分析（约 350 字）

> **方案一：Radiopaedia（国际放射学百科 + 病例库）。** 功能：文章、病例、解剖模块、quiz、课程；关键词搜索与分类浏览；病例多帧与影像标注。门槛：英文；注册；部分功能需 All-Access 订阅；内容 CC BY-NC-SA，不可商业再分发。成本：个人免费层 + 订阅，机构授权另计。覆盖：放射科医生、住院医、医学生的日常参考、考试复习与 CME。不足：答案停留在文章级/病例级，不绑定分区 bbox 与文献条款；无中文课堂与学情。
>
> **方案二：推想 InferRead DR Chest（胸片 AI 辅助筛查）。** 功能：DICOM 胸片输入；结核、结节、骨折、气胸、积液等检出；热图、位置、概率、结构化报告。门槛：医院采购与合规培训；PACS/RIS 集成；私有化部署。成本：院内 license/年费，公开中标案例为数十万元级。覆盖：影像科、体检、基层结核筛查、远程放射。不足：输出概率与位置，不解释文献依据；不做教学分区、课堂与作业评分。
>
> **差异：** Radiopaedia 把知识组织到“文章/病例”，InferRead 把 AI 输出到“病灶/概率”；RadioCheck 把证据下沉到“教学分区”，让每条答案同时带影像锚点与文献锚点，并用 `unmentioned` 第四态区分“来源未提及”与“正常”。

### 5.2 创新性三条（约 300 字）

> **创新点：把影像教学答案从“文章级/病灶级”下沉到“分区级”，并让每条答案同时绑定影像位置与文献条款。**
>
> **差异一（证据粒度）：** Radiopaedia 的答案是文章/病例级，InferRead 的输出是病灶/概率级；我们把答案绑定到“病例 id + 分区名 + 状态 + bbox + 许可”与“征象 id + 来源标题 + 链接”，两个锚点都能点开原图复核。缺任一侧就降级或拒答。
>
> **差异二（不确定性）：** 竞品通常把“没描述”默认为正常，或把模型阴性当作正常；我们设 `unmentioned` 第四态，153 个分区中有 58 个（37.9%）处于该状态，界面明确写“不作推断”，代码与评分规则都禁止把它渲染成 `normal`。
>
> **差异三（教学闭环）：** Radiopaedia 的 quiz 是个人自测，InferRead 不做教学；我们把证据结构变成定位（40）、判读（30）、征象（30）三道可评分任务，支持教师布置、自动评分、学情回流与错题重练，评分只对照库内标注，不评价临床诊断。

> 答辩时补一句边界：“以上差异均可在仓库中按文件核对；我们不主张‘全球首个’，只主张‘据公开资料，未见同类教学产品把证据做到分区级并保留第四态’。”
