# 人体解剖首页 · 接口说明

首页基于 BodyParts3D 4.0 搭建，用全身 3D 模型做部位导航：悬停看结构、点击选部位、进入对应影像知识库。
本文件说明**跳转接口的契约**，便于后续替换知识库入口或嵌入其他宿主页面。

- 首页地址：`http://localhost:8765/homepage/`
- 知识库地址：`http://localhost:4180/`
- 代码位置：`homepage/`

## 1. 启动

```bash
# 方式一：一键启动（同时起首页与知识库）
./homepage/start.command

# 方式二：手动
python3 homepage/serve.py --port 8765      # 首页 + 模型静态资源
python3 kb/scripts/serve.py --port 4180    # 知识库 JSON API
```

首页必须先由 HTTP 服务打开。直接双击 `index.html`（`file://`）会因浏览器安全策略无法读取模型。

## 2. 跳转契约

点击部位后，默认跳转规则：

```
{kbPath}?region={REGION_ID}
```

当前配置（`homepage/data/regions.json` 每条的 `kbPath` / `kbQuery`）：

```
http://localhost:4180/?region=REG-CHEST
```

| 部位 ID | 名称 | 3D 单元 | 组数 | 图数 |
| --- | --- | --- | --- | --- |
| `REG-CHEST` | 胸部 | lung, heart, ribcage | 6 | 18 |
| `REG-HEAD-NECK` | 头颈部 | skull, brain, neck | 3 | 7 |
| `REG-BREAST` | 乳腺 | 无（模型未收录） | 1 | 6 |
| `REG-ABDOMEN` | 腹部 | liver, gitract, kidney, pancreas | 1 | 1 |
| `REG-MSK` | 肌骨与脊柱 | spine, pelvis, limbs | 1 | 0 |

知识库侧已支持 `?region=`：打开后自动切到「图像对照」并按部位过滤。
若部位 ID 不在库内，会退回全部影像并提示。

## 3. 运行时 API

首页暴露 `window.AnatomyHomepage`：

```js
window.AnatomyHomepage = {
  version: "1.0.0",
  regions,                  // 部位元数据数组
  ready,                    // 模型是否加载完成
  getRegion(regionId),      // 取单个部位
  selectRegion(regionId),   // 选中部位（高亮 + 打开右侧面板，不跳转）
  enterRegion(regionId),    // 进入部位（触发 navigator）
  clearSelection(),         // 取消选中
  setNavigator(fn),         // 接管跳转，传 null 恢复默认
  on(event, handler),       // 订阅事件，返回取消订阅函数
  emit(event, payload)
}
```

### 事件

| 事件 | 触发时机 | payload |
| --- | --- | --- |
| `ready` | 模型与数据加载完成 | `{ regions, manifest, failed }` |
| `select` | 选中 / 取消选中 | `region` 或 `null` |
| `enter` | 进入某部位 | `region` |

### region 结构

```json
{
  "id": "REG-CHEST",
  "name": "胸部",
  "en": "Chest",
  "order": 1,
  "note": "肺、胸膜、纵隔与胸壁；含正常胸部与成像条件对照。",
  "units": ["lung", "heart", "ribcage"],
  "meshNote": "",
  "groups": [
    { "id": "GRP-LUNG-CONSOLIDATION", "name": "肺部实变与气腔影", "modality": ["CR", "CT"], "bodyPart": "肺", "images": 5 }
  ],
  "groupCount": 6,
  "imageCount": 18,
  "kbPath": "http://localhost:4180/",
  "kbQuery": { "region": "REG-CHEST" }
}
```

## 4. 三种接入方式

### 4.1 替换跳转目标

```js
AnatomyHomepage.setNavigator((region) => {
  location.href = `/kb/${region.id}`;
});
```

`navigator` 可以返回 Promise，首页会等待并捕获异常。

### 4.2 同页嵌入，不整页跳转

```js
AnatomyHomepage.setNavigator((region) => {
  const frame = document.getElementById("kb-frame");
  frame.src = `http://localhost:4180/?region=${region.id}`;
  document.getElementById("kb-panel").hidden = false;
  return false;
});
```

### 4.3 监听事件做埋点或联动

```js
AnatomyHomepage.on("enter", (region) => {
  analytics.track("anatomy_enter", { region: region.id });
});

AnatomyHomepage.on("select", (region) => {
  console.log(region ? region.name : "cleared");
});
```

## 5. 直接链接到某个部位

首页本身也接受参数，便于从其他页面反向跳入：

```
http://localhost:8765/homepage/?region=REG-ABDOMEN
```

打开后自动选中该部位并高亮，不触发跳转。

## 6. 模型数据

`homepage/public/models/` 由 `homepage/tools/build_models.py` 生成：

```bash
python3 homepage/tools/build_models.py \
  --src <BodyParts3D 解压目录>/partof_BP3D_4.0_obj_99 \
  --out homepage/public/models
```

处理流程：按 FMA 概念合并 OBJ → 顶点聚类简化到目标面数 → 统一 mm→m、Z-up→Y-up。
结果 13 个可点击单元 + 1 个体表轮廓，约 49.5 万三角面 / 13 MB。

导航数据由知识库生成：

```bash
python3 homepage/tools/build_regions.py --kb kb --out homepage/data/regions.json
```

改了 `kb/data/taxonomy.json`、`groups.jsonl` 或 `cases.jsonl` 后重跑一次即可同步组数与图数。

## 7. 已知边界

- **BodyParts3D 的 PART-OF 树未收录**甲状腺、乳腺、脾、喉。因此乳腺只有列表入口，没有 3D 高亮；头颈部以颅骨、脑、气道与颈椎表示。
- 肺模型自带支气管树分支，视觉上偏细碎，已通过降低不透明度弱化。
- 模型是成年男性单一个体，不是患者数据，**不可用于形态测量或诊断**。
- 体表轮廓为视觉辅助，不参与点击拾取。
