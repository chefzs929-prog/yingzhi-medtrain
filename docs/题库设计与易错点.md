# 题库设计与易错点联系

> 版本：v3.2 · 2026-11-16
> 数据来源：`kb/data/signs.jsonl`（60 个征象）的 `appearance` / `modality` / `pitfalls` 原文
> 生成代码：`medtrain/build_data.py` 的「考点题库」段
> 前端：`medtrain/app/drill.js`（`quizList` / `quizActive` / `weakPitfalls`）

## 1. 两套题库

| 题库 | 数量 | 依据 | 入口 |
| --- | --- | --- | --- |
| 病例演练 | 29 例 | 有 `sign_tags` 的病例 + 正常对照 | `#/drill` → 病例演练 |
| 考点练习 | 179 题 | 60 个征象 × 3 类题型 | `#/drill` → 考点练习 |

病例演练是「在影像上做四步」，考点练习是「在概念上做辨析」。两者共用同一套 `pitfalls`，所以错题能落到同一个易错点上。

## 2. 题型设计

题型参考国内影像学考试（执业医师、规培结业、放射职称）的常见考法，**题目内容全部来自知识库原文，不是任何考试的真题**。

| 题型 | 数量 | 题干 | 选项来源 | 考点 |
| --- | --- | --- | --- | --- |
| 定义辨析 `define` | 60 | 影像表现原文 | 同部位征象名 + 全库补足 | 描述 → 名称的对应 |
| 检查选择 `modality` | 60 | 征象名 | 单模态（多选） | 该征象依赖哪些检查 |
| 易错辨析 `pitfall` | 59 | 征象名 | 本征象 pitfalls + 跨部位 pitfalls | 哪些坑属于这个征象 |

### 2.1 为什么是这三类

- **定义辨析**：`appearance` 是唯一描述，四选一不会出现「多个正确答案」，判分可靠。
- **检查选择**：`modality` 是显式字段。改成单模态多选，避免旧方案里「正确组合包含在干扰组合中」的歧义。
- **易错辨析**：直接考 `pitfalls`，把「易错点」从提示文案变成可作答的内容。

### 2.2 干扰项怎么造

| 题型 | 干扰项规则 |
| --- | --- |
| 定义辨析 | 同 `body_part` 优先，不足从全库补；排除自身 |
| 检查选择 | 全库出现过的其他模态；不含正确模态 |
| 易错辨析 | 只取**其他部位**征象的 pitfalls，且不含本征象名；含通用词的（层厚/窗宽/体位/伪影等）不作干扰项 |

通用词排除的原因：这类表述对多个征象都成立，放进干扰项会造成「正确答案不唯一」。

## 3. 易错点联系的三个落点

| 位置 | 展示内容 | 实现 |
| --- | --- | --- |
| 考点练习答题后 | 本题易错点（该征象全部 pitfalls） | `quizActive` 的 `.quiz-pit` |
| 病例演练结果页 | 本例易错点，错题时标注「错题已归入」 | `drillResult` 的 `.quiz-pit` |
| 考点题库首页 | 你的高频易错点（错题关联 pitfalls 去重，取前 5） | `weakPitfalls()` |
| 考点题库首页 | 「只练错题」筛选：只保留最近一次做错的题 | `quizPool()` |

错题聚合逻辑：

```js
// 只统计「最近一次做错」的题，避免做对之后仍留在易错点里
const wrongIds = Object.entries(progress.quiz)
  .filter(([, v]) => !v.lastCorrect)
  .map(([k]) => k);
```

## 4. 判分规则

- **全对才算对**：多选必须完全一致，少选、多选都记错。
- **记录维度**：`progress.quiz[q.id] = { done, wrong, lastCorrect, date }`。
- **正确率**：按「最近一次是否正确」统计，不是按历史次数，避免刷题拉高正确率。

## 5. 诚实地界

| 可以说 | 不要说 |
| --- | --- |
| 题型参考考试常见考法 | 这是××年真题 |
| 题目内容来自知识库原文，附出处 | 题目由专家命题 |
| 判分按知识库标注 | 判分符合考试标准答案 |
| 覆盖 60 个征象、179 道题 | 覆盖全部考点 |

`pitfall` 题的正确项来自知识库对**该征象**的标注；解析里写明「按知识库标注」，避免被理解为医学真值的唯一答案。

## 7. 已知局限

1. **只有 29 例病例能出四步题**：120 个病例里只有 24 个有 `sign_tags`，其余是解剖/正常对照。要扩到更多病例，需要上游补标注。
2. **`pitfall` 题存在语义重叠风险**：跨部位干扰项仍可能与本征象相关（如「需与胸膜增厚区别」对肺部征象也可能成立）。当前用「按知识库标注」限定判分口径。
3. **模态题区分度有限**：同一部位多数征象都是 CT，题目偏简单。后续可按「首选检查」而不是「包括哪些」重做。
4. **没有难度分级，也没有「考试高频」标记**：知识库没有考试频次数据，不编造「高频考点」标签；
   当前只有「只练错题」这一种可证明的个性化筛选。
