# 阅片四页整合与界面统一（2026-11-19）

> 范围：`kb/app/` 下的教学、临床、组卷、对照四页，及其静态产物 `outputs/medtrain/read/`。
> 目标：合并相似功能、突出赛题主链路、统一界面风格；保留四个独立 URL。

## 1. 整合前的三个问题

| # | 问题 | 证据 |
| --- | --- | --- |
| 1 | 三套视觉语言并存 | 主应用亮色青绿 `#0e7c7b`；教学页暖白纸感 `#f6f1e8`；临床/组卷/对照深色 `#0b1015` |
| 2 | 顶栏各写各的 | 教学页 `.top` 76px、临床页 `.bar` 58px；品牌符号 `◧` / `◫` 不统一；导航链接硬编码在四个 HTML 里 |
| 3 | 样式与功能重复 | `paper.css`、`compare.css` 各自复制一份 clinic 的 40 行设计令牌与顶栏规则；教学页的随堂自测与组卷页的作答功能重复 |

## 2. 决策

| 决策项 | 结论 | 理由 |
| --- | --- | --- |
| 排序主轴 | **命题主链路优先** | 赛题要求「输入影像 → 区域定位 → 文献溯源」，工作台是唯一完整实现该链路的页面 |
| 视觉基线 | 主应用亮色青绿 | 与官网、主应用同一品牌；影像画布单独保持深色，兼顾看图对比度 |
| 页面形态 | 保留四个独立页面 | 教学投屏、学生单独打开组卷链接、离线分发都需要稳定 URL |
| 导航 | 统一为「工作台 / 图谱 / 组卷 / 对照」 | 四项按「做 → 学 → 测 → 查」排列，工作台排第一 |
| 入口 | `read/index.html` 与主应用「读」入口都指向 `clinic.html` | 评委与用户第一眼进入命题主链路 |

## 3. 四页新分工

| 页面 | 定位 | 保留 | 删除/移出 |
| --- | --- | --- | --- |
| `clinic.html` | **命题主入口**：读片工作台 | 选片/上传、拖框定位、分区命中、双引用、问答、审计；新增三步链路条 | 顶栏的等级筛选下沉到左栏；顶栏不再堆演示控件 |
| `teach.html` | 系统学习：分区图谱 | 章节树、病例列表、分区讲解卡、标记已学；新增「在工作台打开此病例」深链 | 删除随堂自测浮层与判分逻辑（与组卷页重复），改为「去组卷自测」链接 |
| `paper.html` | 检验：组卷与自测 | 组卷、作答、汇总、导入导出 | 无功能删除；按钮样式并入共享层 |
| `compare.html` | 第二知识源：报告对照 | 拆句、指南召回、逐条出处 | 无功能删除 |

## 4. 代码层面的合并

新增两个共享文件：

- `kb/app/base.css`：设计令牌（亮色青绿 + 深色画布变量）、统一顶栏 `.bar`、导航 `.switch`、按钮、卡片、徽标、空态、三步链路。
- `kb/app/common.js`：导航数据与渲染、`?case=` 参数读取、toast、fitFrame。

四页 HTML 只保留 `<header class="bar" data-page="...">`，品牌与导航由 `common.js` 注入；改导航只需改一处。`paper.css` / `compare.css` / `clinic.css` / `teach.css` 删除各自的 `:root` 令牌与顶栏规则，只保留工作区布局。

## 5. 顺带修掉的冲突

- `paper.css` 的汇总柱状条类名 `.bar` 与顶栏 `.bar` 冲突，把顶栏布局覆盖成 grid。已改为 `#repBox .bar`。
- 临床页分区卡片的 `patient_side` 直接输出英文 `right/left`，已统一为「患者右侧 / 患者左侧 / 中线」。
- 顶栏品牌在窄屏被挤压截断，已给 `.logo` 加 `flex:0 0 auto` 与 `min-width:max-content`。
