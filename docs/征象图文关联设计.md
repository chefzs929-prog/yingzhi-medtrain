# 征象文字 ↔ 影像位置关联 · v1 设计

> 版本：v1.0 ｜ 日期：2026-11-15 ｜ 对应作品：赛道 B · 医学影像知识问答（路线 03）
> 承接：[影像区域定位与双引用设计](影像区域定位与双引用设计.md)、`kb/` 三库实现
> 在线界面：`python3 kb/scripts/serve.py --port 4180` →「图文对照」
> 离线演示：`outputs/sign-image-demo.html`

---

## 0. 一句话定位

把征象词条里**一句具体的文字表述**，锚定到公开影像上**一块具体的区域**；
点文字高亮图上的框，点框回到对应的文字。两边必须同时存在，缺一条就不进页面。

v1 先解决“这句话在图上是哪儿”，不做病灶检测、不做自动判读、不给诊断结论。

---

## 1. 为什么需要它

现有 `kb/` 已经能把「征象词条」和「公开影像」关联起来，但关联粒度是 `cases.jsonl` 里的 `sign_tags`：

| 现状 | 问题 |
| --- | --- |
| 一张图挂 1—2 个征象 id | 只能回答“这张图和实变有关”，不能回答“实变的哪句话对应图上哪一块” |
| 征象文字是整段 `appearance` | 用户读完仍不知道“密度均匀增高”在图上是什么样 |
| 影像侧只有整图 | 没有空间锚点，无法核对结论与影像是否对得上 |

所以 v1 的核心工作量不在界面，而在**新增一层“文字锚点 + 图像锚点”的数据结构**，并给它配校验门禁。

---

## 2. 能力边界（先写清楚不做什么）

| 不做 | 原因 | 界面表现 |
| --- | --- | --- |
| 不做病灶检测 / 分割 | 需要训练数据与器械资质，与教学定位冲突 | 框叫“标注区域”，不叫“病灶轮廓” |
| 不判断框内是不是病变 | 同上 | 文案只说“该区与文字表述对应”，不说“检出” |
| 不给诊断结论 | 合规底线 | 页面固定声明；不出现“诊断为”“建议手术”等表述 |
| 不做自动测量 | 无 DICOM 像素标定 | 只给归一化相对位置，不显示 cm / mm |
| 不给未标注区域编造位置 | 宁可说不知道 | 没建立关联的征象不进入「图文对照」选择器 |

**一句话**：定位的是**教学标注区域**，不是病灶；这句话同时出现在数据字段、界面文案和答辩口径里。

## 3. 数据结构

新增 `kb/data/sign_links.jsonl`，一行一条关联。v1 共 12 条，覆盖 9 个征象、9 句文字锚点、9 张公开影像、14 个标注区域。

```json
{
  "id": "SL-001",
  "sign_id": "SIGN-002",
  "quote": "肺实质密度均匀增高，掩盖其内血管走行",
  "image_id": "CASE-006",
  "regions": [
    {
      "bbox": [0.09, 0.37, 0.34, 0.37],
      "label": "右肺中下野",
      "image_side": "left",
      "patient_side": "right",
      "laterality_rule": "pa_chest: image_left = patient_right",
      "atlas_level": "global",
      "note": "图像左侧为患者右侧；框为教学示意，不是病灶分割。"
    }
  ],
  "caption": "红色箭头所指的右肺中下野片状致密影，覆盖该区血管纹理。",
  "reading": "该区密度均匀增高、血管边缘不易分辨，与“掩盖其内血管走行”对应。",
  "basis": "source_label",
  "evidence": {
    "source_id": "SRC-COMMONS",
    "source_page": "https://commons.wikimedia.org/wiki/File:X-ray_of_lobar_pneumonia.jpg",
    "note": "标注依据来源页公开描述与图中红色箭头；区域为人工教学标注。"
  },
  "annotator": "human",
  "annotated_at": "2026-11-15",
  "review": "single_review",
  "status": "active"
}
```

### 3.1 字段约束

| 字段 | 约束 | 说明 |
| --- | --- | --- |
| `quote` | 必须是 `signs.jsonl` 中该征象 `appearance` 的**原文片段** | 不做模糊匹配；改一个字就校验失败 |
| `image_id` | 必须存在，且该影像 `sign_tags` 包含 `sign_id` | 防止图文跨主题硬绑 |
| `regions[].bbox` | `[x, y, w, h]`，归一化 0—1，宽高 ≥ 0.02 | 与分辨率解耦；换图尺寸不用重标 |
| `regions[].label` | 非空 | 例如“右肺中下野”“后肋膈角（侧位）” |
| `regions[].laterality_rule` | 必须在白名单 | 显式声明侧别映射，禁止从方位默推 |
| `basis` | `source_label` / `source_description` / `teaching_estimate` | 区分“原图自带标注”“来源页描述”“教学估计” |
| `annotator` | 固定 `human` | 不允许写模型 |
| `review` | `single_review` / `double_review` | v1 全部为单次人工标注，界面如实显示 |
| `status` | `active` / `deprecated` | 只有 `active` 进入查询 |

### 3.2 侧别规则（零容忍）

图像坐标的左右不等于患者左右，v1 用 `laterality_rule` 显式声明：

| 规则 | 模式 | 适用 | 要求 |
| --- | --- | --- | --- |
| `pa_chest` | 镜像 | PA 胸片 | 图像左 = 患者右，两侧字段必须相反 |
| `ap_chest` | 镜像 | AP / 床旁胸片 | 同上 |
| `axial_ct` | 镜像 | 轴位 CT | 同上 |
| `axial_mr` | 镜像 | 轴位 MR | 同上 |
| `lateral_chest` | 无左右 | 侧位胸片 | 两侧字段必须为空，只定位前后 |
| `us_local` | 无左右 | 超声 | 只给图像内相对位置，`atlas_level=local` |
| `mg_mlo` | 无左右 | 乳腺 MLO | 无 R/L 标记时不推断左右 |

v1 的乳腺与超声条目刻意按 `local` 处理：界面明确写“该模态无全身定位参考，分区仅为图像内相对位置”。
这不是功能缺失，是**诚实的能力声明**。

## 4. 双向定位交互

```
┌─────────────────────────────┬─────────────────────────────┐
│ 文字表述                     │ 影像                         │
│ 肺实质密度均匀增高，          │ ┌─────────────────────────┐ │
│ 掩盖其内血管走行 ①           │ │  黄色框 = 标注区域        │ │
│ ，常可见空气支气管征。        │ │  红色框 = 当前选中        │ │
│                             │ └─────────────────────────┘ │
│ ① CASE-006 大叶性肺炎        │ 图 1/3  [缩略图] [缩略图]     │
│ ② CASE-015 右中上肺野        │ 区域：右肺中下野              │
│ ③ CASE-005 床旁片            │ 对照说明：…                  │
└─────────────────────────────┴─────────────────────────────┘
```

| 操作 | 结果 |
| --- | --- |
| 点带下划线的文字 | 右侧切到该文字对应的影像，框高亮，列表同步选中 |
| 点图上的编号框 | 左侧对应文字高亮，列表滚到对应条目 |
| 点缩略图 | 切换到同一征象的另一张影像，文字锚点保持不变 |
| 点列表条目 | 图、文、框三者同步 |
| 从检索卡片进入 | 卡片显示“图文对照 · N 处”，直接打开该征象 |
| 从影像灯箱进入 | 灯箱显示“可对照征象”，点征象名跳回文字 |

同一句文字可以关联多张影像（例如“实变”的同一句话对应 3 张图），文字只高亮一次，缩略图和列表展开 3 条。

## 5. 接口契约

| 接口 | 方法 | 说明 |
| --- | --- | --- |
| `/api/sign-index` | GET | 已建立图文关联的征象清单，含关联数、影像数、文字锚点数 |
| `/api/sign/<id>` | GET | 单个征象的完整对照：`segments` + `links` + `images` + `stats` |
| `/api/sign-links?sign=&image=` | GET | 按征象或影像筛选关联，供外部脚本与灯箱使用 |

`/api/sign/<id>` 的 `segments` 把 `appearance` 切成普通片段与锚点片段，前端只负责渲染，不自己算偏移：

```json
{
  "sign": { "id": "SIGN-002", "name": "实变", "link_count": 3 },
  "segments": [
    { "start": 0, "end": 18, "text": "肺实质密度均匀增高，掩盖其内血管走行",
      "link_ids": ["SL-001", "SL-002", "SL-003"] },
    { "start": 18, "end": 29, "text": "，常可见空气支气管征。", "link_ids": [] }
  ],
  "links": [ { "id": "SL-001", "image": { "id": "CASE-006" }, "regions": [ ... ] } ],
  "images": [ { "image": { "id": "CASE-006" }, "links": [ ... ] } ],
  "stats": { "links": 3, "images": 3, "regions": 3, "quotes": 1,
             "missing_image": 0, "missing_text": 0 },
  "note": "框是人工标注的教学区域，不是模型识别，也不是病灶分割。"
}
```

同时，`/api/search` 返回的征象对象增加 `link_count` / `linked_image_count` / `linked_image_ids`，
影像对象增加 `link_count` / `linked_signs`，让检索卡片和灯箱无需额外请求就能显示入口。

## 6. 校验与门禁

`kb/scripts/sign_links.py` 是唯一的校验入口，`KB` 初始化、合规检查、测试三处共用：

| 检查 | 失败处理 |
| --- | --- |
| id 唯一且形如 `SL-001` | 报错 |
| 征象 / 影像存在 | 报错 |
| `quote` 是 `appearance` 原文片段 | 报错 |
| 文字锚点不重叠 | 报错 |
| bbox 在 0—1 内、宽高 ≥ 0.02 | 报错 |
| 侧别规则在白名单、镜像两侧相反 | 报错（零容忍） |
| `basis` / `review` / `status` 合法 | 报错 |
| `annotator=human`、日期有效 | 报错 |
| `evidence.source_id` 已登记、`source_page` 为 https | 报错 |
| 影像 `sign_tags` 包含该征象 | 报错 |
| 越界表述、隐私模式 | 合规门禁报错 |

校验失败时 `KB` 直接抛错，不带病上线；命令行可单独跑：

```bash
python3 kb/scripts/sign_links.py
python3 kb/scripts/compliance_check.py
```

## 8. 已知限制

1. **单次人工标注**：v1 全部为 `single_review`，未做双人 IoU 复核；界面如实显示“单次人工标注”。
2. **框是矩形近似**：v1 用归一化矩形，未做多边形贴合；正式标注需在原始分辨率上复核。
3. **覆盖有限**：12 条关联集中在胸部、甲状腺、乳腺；肌骨、腹部尚无图文关联。
4. **部分区域依据来源描述**：`basis=source_description` 表示区域来自来源页公开描述 + 人工估计，不是原图箭头；界面按 `basis` 区分。
5. **多图拼接只取单面板**：`CASE-019` 等多面板图未纳入 v1，避免跨面板坐标歧义。
6. **不做图像内容识别**：检索仍是文字检索，框不会自动生成。

## 9. 3 分钟演示脚本

| 时间 | 动作 | 要讲的一句 |
| --- | --- | --- |
| 0:00—0:25 | 检索“实变”，点卡片“图文对照 · 3 处” | “我们把征象的一句话，锚定到图上的一块区域。” |
| 0:25—0:55 | 点带下划线的“肺实质密度均匀增高…” | “点文字，图上的框亮；三张图是同一句话的三个例子。” |
| 0:55—1:25 | 点第二张缩略图，再点图上的框 | “点框，文字回到原句；两边是同一个数据结构的两个视图。” |
| 1:25—1:50 | 切到“胸腔积液”，指双侧框 | “一张图两个区域，左右分别标；侧别由规则显式声明。” |
| 1:50—2:15 | 切到“甲状腺低回声结节” | “超声没有全身定位参考，我们只说图像内相对位置，不硬给左叶右叶。” |
| 2:15—2:35 | 打开灯箱，点“可对照征象” | “从图也能回到文字，不是单向标注。” |
| 2:35—2:50 | 指门禁统计 | “12 条关联、9 张图、14 个区域，缺图 0、缺文 0。” |
| 2:50—3:00 | 指页脚声明 | “框是人工教学标注，不是模型识别，也不是诊断。” |
