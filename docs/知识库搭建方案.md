# 医学影像知识库搭建方案

> 适用作品：赛道 B · 医学影像知识问答（路线 03「报告—指南双源对照」）
> 版本：v1.0 ｜ 制定日期：2026-11-15 ｜ 提交截止：2026-11-24 18:00
> 约束：核心链路（知识库接入、技能与工作流编排、Agent 运行）全部在 DeepWorks 内完成，不引入外部框架或自建后端作为主体。

---

## 0. 一页速览

| 项目 | 结论 |
| --- | --- |
| 建几个库 | **2 个主库 + 1 个可选词表库**：报告库、指南库、（术语缩写库） |
| 为什么不合并 | 两类语料的召回口径、引用格式、冲突处理方式完全不同，混库会互相污染 |
| 切片单位 | 报告按「结论 / 所见（再按部位）」切；指南按「推荐条款」切，不按页切 |
| 检索方式 | 元数据硬过滤（模态 + 部位）+ 关键词与向量混合召回，每库 TopK=20，重排取 5 |
| 回答形态 | 报告结论与指南条目**逐条并列、各自标出处**；两源冲突时并列展示，不让模型裁决 |
| 质量门槛 | Recall@5 ≥ 85%、引用可回溯 100%、越界拒绝 100%、P95 ≤ 15s |
| 最小可行版 | 400 份报告 + 3 份指南 + 20 条评测，能跑通「提问→双源召回→带出处回答」 |
| 最大风险 | 切片破坏否定词与左右侧，导致语义反转；必须整句切、不按字符硬切 |

**一句话定位**：把影像报告的「征象描述」做成可检索语义层，答案回链到具体报告段落与指南条款，冲突不裁决、越界不硬答。

## 1. 目标与验收标准

### 1.1 服务对象与真实任务

| 用户 | 场景 | 现有做法 | 缺口 |
| --- | --- | --- | --- |
| 影像科规培医生 | 夜班遇到少见征象，想找既往相似病例与依据 | 科室群问人、PACS 标题检索、人工翻 PDF | 只能匹配标题与结论，检索不到「征象描述」 |
| 影像研究生 | 在千余份历史报告中筛同类病例做课题 | 人工翻 PDF，一天二三十份 | 不可复现、无出处、无批量语义筛选 |

### 1.2 验收标准（可测、可写进说明书）

| 指标 | 目标值 | 测量方式 |
| --- | --- | --- |
| 报告检索 Recall@5 | ≥ 85% | 15 条报告类用例，人工判定命中 |
| 指南问答正确率 | ≥ 80% | 10 条指南类用例，对照条款原文 |
| 引用可回溯率 | 100% | 抽查每条引用能否定位到原文段落/页码 |
| 越界拒绝率 | 100% | 5 条对抗用例（库外问题、诊断请求） |
| 端到端 P95 延迟 | ≤ 15s | 30 次提问计时 |
| 演示稳定性 | 连续 3 次全流程无中断 | 彩排记录 |

> 说明：指标只用于自评与迭代记录，不对外宣称临床性能；作品内置「非诊断用途」声明。

## 2. 语料范围与合规底线

### 2.1 语料清单

| 库 | 内容 | 规模（最小 → 目标） | 来源要求 |
| --- | --- | --- | --- |
| 报告库 | 影像检查报告（CT/MR/US/DR），含「影像所见」「印象/结论」 | 400 → 1200 份 | 脱敏或模拟数据，须有科室/指导方同意记录 |
| 指南库 | 公开指南、专家共识、分类标准（如甲状腺结节、乳腺、肝脏影像分类） | 3 → 6 份 | 公开发布版本，记录机构、年份、版本号、链接 |
| 词表库（可选） | 缩写与同义词（TI-RADS、BI-RADS、LI-RADS、常见征象别称） | 100 → 300 条 | 自行整理，标注来源 |

**取舍原则**：宁少勿滥。1200 份质量不齐的报告，不如 400 份字段完整、脱敏彻底的报告。指南只收**当前有效版本**，旧版单独标记 `deprecated`，避免版本混召回。

### 2.2 脱敏清单（逐项打勾后才允许入库）

- [ ] 姓名、身份证号、住院号、门诊号、检查号、病理号
- [ ] 精确日期 → 只保留年份；出生日期 → 只保留年龄段
- [ ] 医院/科室名称、医生签名、设备序列号
- [ ] 图像文件 DICOM 头（若涉及）中的患者信息
- [ ] 正文中夹带的姓名、床号、联系方式（正则 + 人工抽检）

**质检门**：随机抽 30 份做二次复核，命中 1 处未脱敏即整批返工。合规确认对应说明书「赛道 B 未使用真实患者数据」「敏感场景已脱敏」两项勾选。

### 2.3 版权与声明

- 指南：仅入库公开可引用的条款文本，保留出处与链接；不整本转载受限制内容。
- 界面固定展示：「本工具仅用于教学与研究，不构成诊断意见，不能替代医师判断。」
- 不使用真实患者数据做演示；演示用例全部来自脱敏样本或自造样本。

## 3. 双库架构

```
                    ┌─────────────────────────────┐
用户提问 ──► 查询理解 │ 部位 / 模态 / 征象 / 年龄性别 │
                    └──────────────┬──────────────┘
                                   │ 并行召回（各自 TopK=20）
                 ┌─────────────────┴─────────────────┐
                 ▼                                   ▼
        ┌─────────────────┐                 ┌─────────────────┐
        │ 报告库（病例）   │                 │ 指南库（条款）   │
        │ 结论卡 + 所见卡  │                 │ 推荐条款 + 等级  │
        └────────┬────────┘                 └────────┬────────┘
                 └─────────────────┬─────────────────┘
                                   ▼
                        一致性重排（征象匹配）
                                   ▼
                    生成：逐条并列 + 双引用 + 越界拒绝
                                   ▼
                        引用校验（无源句子删除）
```

### 3.1 为什么必须拆成两个库

| 维度 | 报告库 | 指南库 |
| --- | --- | --- |
| 检索目标 | 找「相似病例」 | 找「适用条款」 |
| 关键过滤 | 模态、部位、年龄、性别 | 病种、版本、适用人群 |
| 引用格式 | `[R-0231 · 影像所见]` | `[G-2023-甲状腺 · §4.2 · P12]` |
| 冲突处理 | 病例之间允许差异 | 指南之间按版本优先 |
| 混库后果 | 指南条款挤占病例召回位；病例被当成规范引用 | 同左 |

### 3.2 报告库内部再分两类卡片

一份报告切成两类卡片，用 `report_id` 关联，命中任一卡片都回链整份报告：

1. **结论卡**：印象/结论全文（80—200 字），检索权重最高，用于「有没有类似诊断」。
2. **所见卡**：影像所见按解剖部位切（每段 300—500 字），用于「有没有类似征象描述」。

> 只切结论会丢掉征象层，正是竞品 PACS 的短板；只切所见会让结论被长文本稀释。两类卡片并存是本方案的核心设计。

## 4. 切片规范（决定召回上限）

### 4.1 通用规则

| 规则 | 要求 | 原因 |
| --- | --- | --- |
| 语义完整 | 以句号、分号、换行为边界，**不按固定字数硬切** | 硬切会把「未见」「未除外」切到下一段，语义反转 |
| 否定词保护 | 含否定词的句子必须整句保留，且不得跨片 | 影像报告大量使用「未见明显」「不除外」 |
| 左右侧保护 | 「左侧/右侧/双侧」与征象同片 | 左右错位是致命错误 |
| 测量值保护 | 数值 + 单位 + 部位同片 | 避免「1.2cm」脱离「结节」被改写 |
| 长度上限 | 单卡 ≤ 600 字，超长按部位/段落再分 | 过长稀释向量，过短丢上下文 |
| 重叠 | 相邻所见卡重叠 1 句（约 50 字） | 防止边界信息丢失 |

### 4.2 报告切片

```
输入：一份报告（结构化字段：检查部位 / 检查方法 / 影像所见 / 印象）
输出：
  卡 A（结论卡）
    chunk_type = conclusion
    text = 印象全文
    meta = {report_id, modality, body_part, age_band, sex, exam_year, conclusion_category}
  卡 B…N（所见卡）
    chunk_type = finding
    text = 「部位 + 所见段落」（按部位/段落切，300—500 字）
    meta = {report_id, modality, body_part, finding_tags[], negated(bool)}
```

**反例**：把「甲状腺左叶结节，TI-RADS 4a 类，未见淋巴结异常」按 200 字切成两段，第二段只剩「未见淋巴结异常」，召回时会被当成「无异常」的独立证据。这是必须避免的错误。

### 4.3 指南切片

```
输入：指南 PDF
输出：
  卡（条款卡）
    chunk_type = recommendation
    text = 条款正文（含推荐等级、证据等级）
    meta = {doc_title, org, version_year, section_path, rec_level, evidence_level, page, url, status}
```

- 保留章节路径（如「4.2 随访策略」），否则条款脱离上下文无法判断适用条件。
- 表格转成「表头 + 行」的文本，不丢表头。
- 旧版条款 `status=deprecated`，检索时默认过滤。

### 4.4 切片自检（10 分钟可做）

抽 10 份报告 + 2 份指南，逐条检查：

- [ ] 有没有卡片以「未见」「不除外」「左侧」开头却缺少主语？
- [ ] 有没有数值脱离部位？
- [ ] 有没有一张卡跨了两个部位？
- [ ] 指南卡是否带章节路径与页码？
- [ ] 同一 `report_id` 的卡片能否互相找回？

## 6. 入库流水线（6 步 + 3 道质检门）

```
① 收集定稿 → ② 脱敏 → ③ 结构化解析 → ④ 切片 → ⑤ 打标 → ⑥ 入库冒烟
              ↑质检门1      ↑质检门2              ↑质检门3
```

| 步骤 | 做什么 | 产出 | 质检门 |
| --- | --- | --- | --- |
| ① 收集定稿 | 锁定语料清单，登记来源与授权 | `corpus_manifest.csv` | 缺授权/缺版本的语料直接剔除 |
| ② 脱敏 | 正则批量 + 人工复核 | 脱敏后文本 | 抽 30 份，0 遗漏 |
| ③ 解析 | PDF/Word → 纯文本，保留标题层级与表格 | `parsed/*.txt` | 抽 10 份比对原文，无段落错乱 |
| ④ 切片 | 按第 4 节规则切卡 | `chunks.jsonl` | 切片自检清单全过 |
| ⑤ 打标 | 规则 + 模型抽取元数据 | 带 meta 的 chunks | 抽检 10%，字段准确率 ≥ 90% |
| ⑥ 入库冒烟 | 导入 DeepWorks 知识库，跑 20 条冒烟问句 | 冒烟报告 | 20 条中 ≥ 16 条能召回预期卡片 |

**工程约定**：

- 切片、脱敏脚本属于**建库期离线工具**，放在 `_work/` 或 `scripts/`，不进入运行时链路；运行时只依赖 DeepWorks 知识库与工作流，符合「不以自建后端为主体」的要求。
- 每次重建库都保留 `build_id`（日期 + 语料版本），评测结果与 `build_id` 绑定，便于写迭代记录。
- 先小批量（100—300 份）跑通全链路，再全量导入；不要一次性灌 1200 份后才发现切片错了。

## 7. 检索与生成编排（全部在 DeepWorks 内）

### 7.1 能力映射

| 环节 | DeepWorks 能力 | 说明 |
| --- | --- | --- |
| 语料承载与召回 | 知识库 ×2（报告库、指南库） | 分别建库，分别配置切片与元数据 |
| 查询改写 | 技能 `query_normalize` | 抽取部位/模态/征象，扩展缩写（如 TI-RADS） |
| 征象抽取 | 技能 `sign_extract` | 从提问中抽结构化征象，输出标签 |
| 一致性重排 | 技能 `consistency_rerank` | 判断候选片段与提问征象是否一致，输出排序 |
| 引用校验 | 技能 `citation_check` | 校验回答中每个引用 id 是否存在，删除无源句子 |
| 越界拦截 | 技能 `refuse_guard` | 无召回或低置信时输出固定拒答话术 |
| 串链与重试 | 工作流 | 并行召回 → 重排 → 生成 → 校验，失败可重试 |
| 汇总回答 | Agent | 合并双源结果，输出并列结构与出处 |

> 每个技能单独可被 @ 调用，演示时逐个展示输入输出，同时留下对话截图作为 DeepWorks 使用证明。

### 7.2 检索参数（首版基线，按评测调整）

| 参数 | 基线值 | 调整方向 |
| --- | --- | --- |
| 每库召回 TopK | 20 | 召回不足调 30，延迟超标调 10 |
| 混合权重（关键词:向量） | 3:7 | 缩写/专有名词多时提高关键词权重 |
| 重排后保留 | 5（报告 3 + 指南 2） | 按回答长度调整 |
| 相似度下限 | 0.35 | 低于则进入越界分支 |
| 元数据过滤 | 模态 + 部位硬过滤 | 部位识别失败时退化为软过滤 |

### 7.3 输出模板（固定结构，便于评委看懂）

```
【结论对照】
病例侧：3 份既往报告中 2 份提示「低回声结节伴微钙化」[R-0231·影像所见][R-0417·结论]
指南侧：TI-RADS 4a 类建议 6—12 个月随访 [G-2023-甲状腺·§4.2·P12]

【差异提示】
病例侧 1 份报告结论为「建议穿刺」，与指南随访建议不一致，已并列展示，未做裁决。

【边界声明】
以上为文献与历史病例对照，不构成诊断意见。
```

### 7.4 冲突与越界处理

| 情况 | 处理 |
| --- | --- |
| 报告与指南结论不一致 | 并列展示，标注各自出处，明确「不作裁决」 |
| 指南存在新旧版本 | 只召回 `active`；若用户指定旧版，显式标注版本 |
| 召回为空 / 相似度低 | 走 `refuse_guard`：「库内暂无足够依据，建议咨询专科医师」 |
| 用户要求下诊断 | 拒答 + 说明边界，可提供「就诊提问清单」作为替代 |
| 引用 id 不存在 | `citation_check` 删除该句；删除后无内容则转拒答 |

## 8. 评测方案

### 8.1 用例构成（30 条）

| 类型 | 数量 | 示例 |
| --- | --- | --- |
| 报告检索 | 15 | 「有没有颈动脉内中膜增厚伴斑块的病例」 |
| 指南问答 | 10 | 「TI-RADS 4a 类结节随访间隔」 |
| 对抗/越界 | 5 | 「这个结节是不是癌，要不要手术」；含否定词、左右侧陷阱各 1 条 |

模板见 `outputs/知识库评测用例模板.csv`，字段：`case_id, 类型, 提问, 期望命中(report_id/条款), 期望行为, 实际结果, 判定, 问题归因, build_id`。

### 8.2 判定口径

- **命中**：Top5 中出现期望卡片，或出现同义且人工认可的同部位病例。
- **引用正确**：引用段落确实包含该结论，允许摘要但不得改变语义。
- **越界正确**：明确拒答或转边界提示，且不给出诊断性结论。
- **失败归因**：只允许四类——切片问题 / 召回问题 / 重排问题 / 生成问题。归因决定改哪里，避免盲目调参。

### 8.3 迭代节奏（对应「迭代记录 10 分」）

| 轮次 | 时间 | 动作 | 记录内容 |
| --- | --- | --- | --- |
| v1 基线 | 11/18 | 固定切片 + 纯向量召回 | 30 条结果，记录 Recall@5 |
| v2 切片优化 | 11/19 | 结论/所见分层、否定词保护 | 对比 v1 提升幅度 |
