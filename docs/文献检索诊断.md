# 文献检索诊断：为什么很多查询没有结果

统计口径：停用 5 例非影像素材后的知识库（195 例 / 963 分区 / 967 条结论 / 546 段落 / 47 条指南）。
承接 [`内容重建v2_同质化与文献侧修复记录`](内容重建v2_同质化与文献侧修复记录.md)：v2 已把**结论文本**的唯一率做到 100%，但**文献侧挂接**仍高度集中，这是本文的重点。
数据来自 `kb/data/*.jsonl`，可用 `kb/scripts/audit_case_meta.py` 复跑素材体检。

## 结论先说

**应该扩充，但不是先堆段落数量。** 当前"查不到"的主因不是段落总数不够，而是三件事：

1. 结论与文献的挂接是模板化的，同一段被反复引用；
2. 40% 的病例没有挂到指南条款，头颅与肌骨整类没有指南；
3. 召回入口太窄：只认 60 条征象词条，用户换个说法就 `no-signal`。

在这三条修好之前，把段落从 546 扩到 2000，命中率不会同比例上升。

## 数据事实

### 1. 文献侧高度重复

- 967 条结论只引用了 **23 个不同的文献 id**。
- 其中 **900 条**结论的文献引用包含 `SIGN-001`（磨玻璃影），`GL-FLEISCHNER-04` 被引用 450 次。
- 典型例子：CASE-034「右肺上野」的结论写的是"该区对应表现「磨玻璃影」"，但该病例并没有磨玻璃影标注；CASE-105（腰椎 MRI）原先甚至挂在"脑膜强化"上。

这不是检索算法的问题，是内容生成时"按模板套征象"造成的。检索再准，也只能召回这段模板。

### 2. 指南覆盖不均

| 部位族 | 有指南条款 | 无指南条款 |
| --- | --- | --- |
| 胸部 | 93 | 3 |
| 甲状腺 | 13 | 0 |
| 乳腺 | 1 | 21 |
| 腹部 | 2 | 2 |
| 头颅 | 3 | 15 |
| 肌骨/脊柱 | 5 | 37 |

- 头颅与肌骨在 `GUIDE_FAMILY` 里是空数组，运行时**永远不可能**命中指南，只能降级到征象词条。
- 乳腺库里有 6 条 BI-RADS 指南，但 22 例乳腺只有 1 例的结论挂到了指南；需要输入"BI-RADS 3 类"这类分类词才会在运行时命中。
- 20 条"正常对照"结论原先只有影像侧引用、没有文献侧，任何查询都会以 `no-doc` 拒答（本次已补阴性对照引用）。

### 3. 召回入口太窄

- 只有 60 条征象词条 + 一张同义词表；用户说"白影""片子有点糊""这块密度高"都命中不了。
- 未命中征象时直接 `no-signal` 拒答，用户感知就是"没有结果"。
- 只点分区、不输入文字时，原先也直接拒答"没有可判定的输入"。

### 4. 分片加载放大了"没结果"

知识库按「部位 + 模态」拆 6 片，切病例时才加载。自检脚本若在分片未加载时跨病例运行，会把"还没加载"误判成"没有结论"。
本次已把自检改为先 `loadAllParts()` 再跑，8 条自检全部通过。

## 本次已落地的修复

| 问题 | 处理 |
| --- | --- |
| 只点分区就拒答 | 新增"分区定位"回答：复述该分区库内定位 + 文献段落，状态标 `partial`，明确不做征象判断 |
| 未命中征象只给通用提示 | 拒答时列出当前病例可对照的征象名，并提示可直接点分区 |
| 3 个演示病例分区缺口 | CASE-001/006/011 补齐 18 条分区对照结论 |
| 20 条正常对照缺文献侧 | 补 Lung-RADS 1 类 / 脑膜强化阴性对照引用 |
| 自检跨病例误判 | 自检前加载全部分片，8/8 通过 |

## 扩充建议（按性价比排序）

### P0：先把已有段落挂对

1. 按 `body_part + modality + sign_id` 重新生成结论的 `doc` 引用，禁止所有结论共用 `SIGN-001`。
2. 每个分区至少一条"该分区解剖定位"段落，保证点任何分区都有可引用内容。
3. 把 546 段落里尚未被引用的段落建一张 `sign_id → para_id` 显式索引，检索时先查索引，再做关键词打分。

### P1：补覆盖缺口

1. 头颅：补 CT/MR 常用征象段落（出血、梗死、占位效应、水肿、脑膜强化）与对应指南/共识；没有指南时明确返回"该部位暂无指南条款"，而不是静默降级。
2. 肌骨/脊柱：补骨折、退变、椎间盘、骨髓水肿的段落；本次 CASE-105 已改为腰椎解剖分区，但库内仍无腰椎专用结论。
3. 乳腺：把 6 条 BI-RADS 条款挂到对应象限结论，并在输入含"随访/活检/分类"时优先命中。
4. 扩同义词与口语别名（至少覆盖"白影/黑影/密度高/片子糊/占位/水泡"等常见说法）。

### P2：新增段落

新增文献段落必须逐条登记 `doc_id / 版本 / 定位 / 原文 / SHA-256 / 许可`，并由医学人员审核签字后再进入回答。段落数量不是目标，**可回查、可审核、挂得对**才是。
