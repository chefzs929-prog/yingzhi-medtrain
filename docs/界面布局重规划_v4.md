# 影知 · 界面布局重规划（v4）

> 版本：v4.0 · 2026-11-16
> 取代：[界面布局与首页模型接口.md](界面布局与首页模型接口.md) 第 2–4 节（三档宽度、七个功能区、证据栏规则）中的布局部分；该文档的模型接口契约（5.1–5.4）与病例工作台分区规则继续有效。
> 主轴：**学生端**。教师端 / 医生端沿用同一骨架，只换导航文案与首页模块。

## 0. 决策摘要

| 决策项 | 结论 | 理由 |
| --- | --- | --- |
| 布局主轴 | 学生端 | 主用户是"从术语到病例"的学习者；临床端是同一骨架的进阶形态 |
| 顶栏 | 降级为 56px **上下文条**；角色三键与设备切换合并为右上角**身份按钮**（头像 + 角色 + 箭头），点开才出现切换项 | 演示控件不该占用真实用户的主界面，也不该以调试器的形态出现 |
| 左导航 | 232px，5 个任务项 + 我的；去掉"四链条 / 工作台"分组标题 | 分组标题是内部叙事词，用户不认 |
| 四链条 | 降级为首页 / 关于页的叙事入口，不做一级导航 | 保留产品叙事，不牺牲导航效率 |
| 主区 | 两种工作模式：**阅读模式** / **专注模式** | 检索阅读与任务执行是两种不同的注意力结构 |
| 证据栏 | 保留，**默认收起为 34px**，用户展开后跨页保持 | 消除与页内双引用卡的重复，同时不删能力 |
| 阅读页列数 | 2 列（列表 280 + 详情自适应），删除页内第三列 | 现有 5 列导致标题竖排 |

## 2. 参考范式

| 来源 | 取什么 | 不取什么 |
| --- | --- | --- |
| PACS / RIS（工作列表—阅片—报告） | 病例 banner 固定顶部；左队列 / 中影像 / 右结论；底部"下一例"闭环 | 检查号、序列缩略图、窗宽窗位等影像工作站控件（本项目不做诊断） |
| 影像教学条目站（Radiopaedia 式） | 检索优先；条目页单列阅读宽度；出处作为条目内固定区块 | 社区编辑、评论、多语言切换 |
| 临床知识速查（UpToDate 式） | 左目录 + 右正文；正文层级固定（定义→表现→易错→鉴别→出处） | 订阅墙、专题长文 |
| 教学管理系统 | 首页=待办优先；班级数据一张卡看完 | 排课、考勤等教务模块 |

共同点：**一次只让用户做一件事**。阅读时不摆任务操作，执行时不摆长文。

## 3. 目标动线（学生端主轴）

```
检索（想查一个词）
  → 阅读（学：是什么 / 怎么看 / 易错）
  → 迁移（换模态、换部位还成立吗）
  → 演练（在真实病例上四步作答）
  → 应用（变成任务与记录）
  → 回看（我的：错题、收藏、报告）
```

三条硬约束：

1. **任意页面两次点击内可达检索**：顶栏 ⌘K 与移动端 tabbar「检索」常驻。
2. **上下文不丢**：阅读页切换词条不跳页；工作台切换病例不离开队列；演练退出前有确认。
3. **每页只有一个主动作**：页头右上最多 1 个 primary 按钮，其余降为次级。

### 5.2 阅读模式（`#/learn`、`#/transfer`）

```
页头（64px，一行）
  学 · 基础知识        [去迁移]  [用一例检验]
检索行（一行，不换行）
  [🔍 输入征象或问题 ………………………………] [部位 chips ▾] [模态 ▾]   60 条
┌──────────────────┬───────────────────────────────────────────────┐
│ 征象词条  60/60   │ 磨玻璃影  ground-glass opacity                │
│ ┌──────────────┐ │ [影像] [CT] [肺] [GGO]     [收藏][迁移][找病例] │
│ │磨玻璃影  影像 │ │                                               │
│ │ground-glass  │ │ 肺野密度轻度增高，但内血管与支气管边缘仍可辨认； │
│ │肺野密度轻度… │ │ 不掩盖其内血管与支气管轮廓。                    │
│ └──────────────┘ │ ───────────────────────────────────────────── │
│ 实变        影像 │ 影像表现            │ 易错点                    │
│ 结节        影像 │ · 炎症性渗出        │ · 需与部分实性结节中的实性   │
│ 肿块        影像 │ · 局灶性纤维化      │   成分区分                 │
│ …                │ · 肿瘤性病变        │ · 层厚与窗宽会影响显示       │
│                  │                                               │
│                  │ ▸ 出处与引用（2 条双引用 · 展开）                │
│                  │ ▸ 相关病例（3）                                 │
│                  │ ▸ 相关条款（2）                                 │
│ 280              │ 自适应（≥760 阅读宽度）                          │
└──────────────────┴───────────────────────────────────────────────┘
```

要点：

- 删除页内 `.learn-side`（部位导航 / 本部位 / 3D 解剖三张卡）。部位筛选已在检索行 chips；3D 解剖入口移到产品首页。
- 出处与引用在详情内**默认折叠**，展开后显示文献 + 空间双引用；与右证据栏同源，但只在一处出现。
- 详情单列，正文最大宽度 760px；1440 下详情可用宽度约 800px，≥1100px 时"影像表现 / 易错点"并两栏。
- 列表 sticky，独立滚动；切换词条不重排整页。

### 5.3 专注模式（`#/apply` 医生、`#/drill` 作答中）

```
┌ 病例 banner 52px ─────────────────────────────────────────────────┐
│ CASE-020 · 大叶性肺炎（箭头标注） · CR 胸部 · CC0 · 已核验 0/3      │
├─────────┬──────────────────────────────────┬────────────────────┤
│ 队列 260 │  影像（深色，自适应，最大 62vh）    │ 结论 340            │
│ [搜索]   │  分区编号 overlay                  │ 全部结论 3 条        │
│ 120 例   │                                  │ ┌────────────────┐ │
│ ▸ 正常…  │                                  │ │空间 + 文献 双引用│ │
│ ▸ 正常…  │                                  │ └────────────────┘ │
│ ■ 大叶…  │                                  │ ┌────────────────┐ │
│          │  ① ② ③ ④ ⑤ ⑥ ⑦ ⑧ 图例          │ │单引用 待补空间    │ │
├─────────┴──────────────────────────────────┴────────────────────┤
│ 操作条 56px sticky： [← 上一例] [标记已核验] [生成交班摘要] [下一例 →] │
└─────────────────────────────────────────────────────────────────┘
```

要点：

- 进入即 `body.focus-mode`：左导航收 56px（hover 临时展开），证据栏强制收起，主区内边距 12px。
- 影像高度按视口算：`min(62vh, 影像原始比例)`，保证 1440×950 下影像宽 ≥ 560px。
- 操作条是新增组件 `.wb-actions`，`position: sticky; bottom: 0`；「标记已核验」写 `progress.reviewed`，「生成交班摘要」复用现有 `summaryText()`。
- 分区编号仍只显示数字，名称进图例（沿用 v3.1 规则，不改）。
- 演练作答态同样进专注模式，但操作条换成「上一步 / 下一步 / 退出演练（确认）」。

### 5.5 产品首页（`index.html`）

- 人体模型与右侧面板改为 2:3 而非 420:1fr 定宽，右栏未选部位时显示"最近 4 个部位入口 + 5 个高频征象"，不留白。
- 首屏只保留一句定位 + 两个按钮（以学生身份开始 / 进入系统）。
- 四链条改为一行 4 个横条（不是 4 张大卡）。

## 12. 风险与不做

| 风险 | 处理 |
| --- | --- |
| 证据栏收起后用户找不到引用 | 首次进入阅读页给一次 1.5s 提示气泡（`localStorage` 只显示一次）；折叠条 hover 显示"展开证据栏" |
| 删除 `.learn-side` 后 3D 解剖入口丢失 | 入口移到产品首页人体模型下方，并在「关于」页保留链接 |
| 专注模式隐藏导航导致迷路 | 左上角保留"返回"图标 + 面包屑；`Esc` 退出专注 |
| 首页动线改动影响评审叙事 | 四链条仍在首页底部一行 + 关于页完整呈现，叙事不丢 |
| 分阶段改动交叉 | P0 先合入并验收，P1–P4 各自独立分支，避免同时改 `core.js` |

明确不做：

- 不引入前端框架或构建工具（保持 `build.py` 直接拷贝）。
- 不做窗宽窗位、测量、标注编辑等影像工作站功能。
- 不改 3D 适配器契约与 `REG-*` 部位 id。
- 不新增后端接口；所有数据仍来自 `data/kb.js`。
- 不做视口 / 设备 / 分辨率切换入口：响应式由 CSS 断点自动生效，不给用户暴露调试开关。
- 不在产品界面出现「切换移动视图」「PC / 移动」这类演示按钮，演示时直接改窗口宽度或使用移动端页面。
