# 学生影像实验室与互助小组（2026-11-22）

> 范围：在 v9「21 例 CR 胸片 + 课堂作业」之上，把学生端扩展为 5 个页签：
> **我的作业 / 影像问答 / 读片陪练 / 自测出题 / 互助小组**。
> 目标：让学生不只“做作业”，还能查库内证据、按步骤练读片、自己出题，并在组内论坛提问。
> 不做：账号体系、服务端同步、大模型自由问答、跨部位扩题、诊断/治疗建议。

---

## 1. 为什么加这一层

v9 的课堂只覆盖“教师布置 → 学生作答 → 结果回流”。学生遇到问题时仍缺少三件事：

1. **查证据**：这个征象在库内怎么定义？哪一例、哪一个分区能定位？出处在哪？
2. **练过程**：作业直接给三题，学生没有“先定位、再判读、再选征象”的逐步练习。
3. **问同伴**：错题和读片分歧只能在课堂外解决，没有组内论坛。

v10 在同一个 `read/classroom.html` 学生端内补上这三件事，仍然只围绕 21 例胸片，
仍然纯静态、只写本机 `localStorage`。

## 3. 影像库问答：区域定位 + 文献溯源双引用

### 3.1 检索顺序

前端只读 `kb/data/student_lab.json`，不调用大模型。一次提问按以下顺序打分：

1. `signs`：征象名 / 英文名 / 别名 / 定义 / may_see_in / pitfalls / tags；
2. `concepts`：疾病或病理名 / 英文名 / 别名 / note；
3. `guidelines`：标准名 / 类别 / 条款 / 适用条件；
4. `cases`：病例标题 / 挂载征象名。

取最高分作为主命中；同分时按“征象 → 概念 → 指南 → 病例”顺序。
“实变和胸腔积液怎么区分”这类对比问法，会并列两个库内征象，各给最多 2 个影像位置与易错点。
疾病名命中概念时，先取 `sign_ids`（直接挂载），再取 `related_sign_ids`（关联征象），
并在界面上分别标“直接挂载 / 关联征象”。

### 3.2 双引用

每条命中最多给两组证据：

| 组 | 编号 | 内容 |
| --- | --- | --- |
| 影像定位 | `E1`、`E2`… | 病例 id、病例标题、分区名、分区状态、缩略图上的黄色区域框、影像许可与作者、`clinic.html?case=` 链接 |
| 文献溯源 | `L1`、`L2`… | 征象 id + 名称 + 定义 + `sources` 里的来源标题/链接；命中指南时给 `G1` 条款与适用条件 |

页面底部给一条可核对的“双引用链”：

```
E1 CASE-036 / 右肺上野 → L1 SIGN-008 气胸 → SRC-RADIO
```

链只表示“该病例该区在库内挂载了该征象”，不表示诊断。
同一病例最多展示 2 个分区，避免同一病例刷屏。

### 3.3 未命中

如果四类都没有命中：

- 明确写“库内未命中”；
- 单独一段以 `【通识补充·非库内证据】` 开头；
- 通识段内不出现任何 `SIGN-` / `CON-` / `GL-` 等 id；
- 给“可改查库内词条”的名称按钮，但不把建议标成证据；
- 不回答诊断、治疗、用药、手术或预后。

### 3.4 边界

- 只覆盖 21 例 CR 胸部，不扩 CT / 超声 / 其他部位；
- 影像定位是教学分区框，不是病灶分割；
- 指南命中主要来自肺结节 Fleischner / Lung-RADS 条款，明确标“适用条件”，不把 CT 随访建议外推到胸片；
- 文献只到来源级，不复制受版权保护全文。

## 4. 读片陪练

### 4.1 四步

| 步骤 | 学生动作 | 系统反馈 |
| --- | --- | --- |
| 1 定位 | 点影像分区（可多选），或选“未见明确异常” | 只高亮选择，不显示状态颜色 |
| 2 判读 | 选异常 / 未见异常 / 来源未提及 / 判读受限 | 不立即判对错 |
| 3 征象 | 多选该病例库内挂载征象，或选“未见明确征象” | 不立即判对错 |
| 4 对照 | 点“提交并对照” | 显示病例标题、分区颜色、库内所见、依据、40/30/30 评分 |

### 4.2 提示

每步有“给一个方法提示”，只给方法：

- 定位：按气管与纵隔 → 肺野 → 肺门 → 心影 → 膈面与肋膈角 → 骨骼与软组织顺序扫；
- 判读：四种状态的区别，特别强调“来源未提及 ≠ 正常”；
- 征象：只选库内实际挂载的征象，正常对照不要硬选；
- 对照：先看定位，再看状态与征象，分数只代表库内标注匹配度。

### 4.3 评分与记录

复用 `classroom-core.js` 的 `gradeCase`：

- 定位 40：选中任一异常分区；无异常病例选“未见明确异常”；
- 判读 30：按所选分区的真实状态；
- 征象 30：命中数减错选数的一半，再除以正确征象数；无征象病例选“未见明确征象”得满分。

陪练记录写 `radiocheck.studentlab.v1` 的 `practice`，不进入班级成绩。
病例选择器只显示 `CASE-xxx · 体位`，提交前不显示病例标题，避免直接读出诊断。

## 5. 自测出题器

### 5.1 题库

`kb/scripts/build_student_lab.py` 从 `chest_reading.json` 规则生成 350 题：

| 题型 | 数量 | 生成规则 |
| --- | --- | --- |
| 影像定位 `locate` | 153 | 每个分区一题：给分区框，问属于哪个解剖分区；正位 4 选项、侧位 3 选项 |
| 分区判读 `status` | 153 | 每个分区一题：问该区在库内的状态（四选一） |
| 征象识别 `sign` | 44 | 每个有 `sign_ids` 的分区一题：问该区关联的征象 |

每题带：

- `case_id` / `zone_id` / `coords`：影像与区域框；
- `options` / `answer` / `answer_index`：选项与答案；
- `explain`：库内所见与“不代表诊断”的说明；
- `citations`：病例、分区、征象、来源。

### 5.2 组卷

- 范围：全部 21 例 / 有异常标注 / 正常对照 / 按征象（20 条）；
- 题型：混合 / 只考定位 / 只考判读 / 只考征象；
- 题量：5 / 10 / 15 / 20；
- 限时：不限 / 10 / 20 / 30 分钟。

### 5.3 作答与结果

- 试卷显示影像、区域框、选项、答题卡、倒计时；
- 交卷后逐题给：你的答案、正确答案、解析、影像 `E1` 与文献 `L`；
- 支持“只重做错题”、导出 Markdown 成绩单、保留最近 20 次记录；
- 未答完交卷会二次确认；限时到点自动交卷。

题目是库内规则题，**不是考试真题**；分数只代表与库内逐区标注的匹配度。

## 6. 互助小组

### 6.1 角色

- 教师：创建小组、查看帖子、标记解决、删除小组/帖子、载入演示数据；
- 学生：加入/退出小组、发帖、回复、按“最新 / 待解决 / 我的参与 / 已解决”筛选。

### 6.2 数据模型

班级对象内新增 `groups`，全局新增 `posts`：

```json
{
  "groups": [{
    "id": "GRP-...",
    "name": "肺野读片互助组",
    "topic": "气腔影与正常对照",
    "note": "先定位，再描述密度与边界",
    "createdBy": "STU-...",
    "createdAt": "...",
    "memberIds": ["STU-..."]
  }],
  "posts": [{
    "id": "POST-...",
    "classId": "CLS-...",
    "groupId": "GRP-...",
    "studentId": "STU-...",
    "title": "CASE-007 下肺野密度增高，实变还是积液？",
    "body": "...",
    "caseId": "CASE-007",
    "status": "open",
    "createdAt": "...",
    "updatedAt": "...",
    "replies": [{
      "id": "REP-...",
      "studentId": "STU-...",
      "body": "...",
      "at": "..."
    }]
  }]
}
```

旧数据通过 `normalize` 自动补 `groups` / `posts` / `memberIds` / `replies`，不破坏已有班级与答题记录。

### 6.3 交互

- 帖子可关联 21 例胸片；详情页显示缩略图，点击跳 `clinic.html?case=`;
- 发帖标题 60 字、正文 1200 字、回复 600 字上限；
- 所有文本渲染前转义，避免 HTML 注入；
- 标记解决后进入“已解决”筛选，教师端待解决数同步减少；
- 教师端“载入演示小组与帖子”会创建 3 个组、4 个帖子与回复，便于现场演示。

### 6.4 边界

- 只在本机浏览器，不做账号、鉴权、跨设备同步；
- 不宣称考试级防作弊；学生仍可查看源码或直接读 `localStorage`；
- 不收集真实患者信息；帖子内容由演示者自行输入；
- 教师端可删除帖子，但不做审核日志与版本留痕。
