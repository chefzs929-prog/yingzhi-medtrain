## 2. 统一后的请求链路

```text
浏览器（四页共用 agent.js）
  │  POST /api/ask
  │  {query, surface, conversation_id, mode, context, image?}
  ▼
serve_region.py :4191  ── 同源代理 ──▶  main.py :8800
                                          │
                            mode=auto 先走 agent
                                          │
                            DeepWorks opencode server
                              agent=yingzhi
                              skill=retrieve-sign
                              grep signs.jsonl / concepts.jsonl
                                          │
                    SSE: trace → tool* → delta* → citation* → followup → done
```

### 事件契约

| 事件 | 何时发 | 关键字段 | 前端用途 |
| --- | --- | --- | --- |
| `trace` | 工具完成 / 收尾补发 | `stage, skill, status, ms, hits` | 五段步骤条 |
| `tool` | 工具完成（只发一次） | `tool, skill, detail, status, ms, out_lines` | 工具明细 |
| `delta` | 正文增量 | `text` | 流式正文 |
| `citation` | 正文里的真实 id | `id, type, title, source_url` | 引用卡片 |
| `followup` | 收尾前 | `items, source=rules` | 追问 chips |
| `reset` | 降级/重答前 | `reason` | 清空已输出内容 |
| `done` | 本轮结束 | `served_by, mode, degraded, reason, run_id, trace_url, followups` | 徽标/耗时/trace |

### 请求字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `query` | 是 | 用户问题 |
| `surface` | 否 | `clinic / teach / paper / compare`，用于会话隔离 |
| `conversation_id` | 否 | 不传则按 `surface` 生成；同一 id 在 10 分钟内复用 session |
| `mode` | 否 | `auto`（默认，agent 优先）/ `agent` / `llm` |
| `context` | 否 | 页面上下文，最多 8 个键、每值 300 字；只用于定位，不是证据 |
| `image` | 否 | data URL，上传影像时使用；视觉只负责定位，解释仍由 agent 做 |

## 4. 验收命令

```bash
# 1. 服务与能力
curl -s http://127.0.0.1:8800/api/health | python3 -m json.tool
curl -s http://127.0.0.1:8800/api/agent/capabilities | python3 -m json.tool

# 2. 离线降级（必须 served_by=fallback、degraded=true）
python3 yingzhi/serve/main.py --port 8899 --offline
curl -sN -X POST http://127.0.0.1:8899/api/ask \
  -H 'Content-Type: application/json' \
  -d '{"query":"磨玻璃影","surface":"clinic","conversation_id":"t1"}'

# 3. 真实 agent（应看到 tool、citation、followup、served_by=agent）
curl -sN -X POST http://127.0.0.1:8800/api/ask \
  -H 'Content-Type: application/json' \
  -d '{"query":"磨玻璃影在CT上怎么描述？","surface":"clinic","mode":"agent"}'

# 4. 回放
curl -s http://127.0.0.1:4191/api/trace/<run_id> | python3 -m json.tool

# 5. 静态构建
python3 kb/scripts/build_teach_pages.py
```

判定标准：

- `done.served_by` 必须是 `agent / llm / fallback` 之一，不能为空；
- agent 成功时 `trace` 里 `skill_invoke` 必须是 `retrieve-sign`，不是 `unavailable`；
- `citation` 的 id 必须能在 `kb/data/*.jsonl` 查到；
- `--offline` 下 `agent_ready=false`，不能偷偷连回 agent；
- 同一 `conversation_id` 第二轮 `session_id` 相同，耗时不超过首轮的 2 倍。

## 5. 已补齐：工作流编排与语义检索

这两项过去是 `real_workflow=false`、`semantic_search=false`，现在已落到代码里，不再是材料描述。

| 能力 | 实现 | 怎么验证 |
| --- | --- | --- |
| 工作流编排 | `yingzhi/serve/workflow.py`：`parse → retrieve → locate → compose → audit`，每次 `/api/ask` 真实执行，结果写进 `trace.json` 的 `workflow` span，并单独落盘 `workflow.json` | `GET /api/health` 看 `real_workflow=true`；`GET /api/trace/{run_id}` 看五步；`python3 yingzhi/serve/test_workflow.py` |
| 语义检索 | `yingzhi/serve/semantic.py`：中文 1–2 gram + 英文词 + 别名/口语改写的 TF-IDF 稀疏向量，L2 归一化后按余弦排序；不是 grep | `GET /api/kb/search?q=毛玻璃结节&mode=semantic`；`python3 yingzhi/serve/test_semantic.py` |

边界（不夸大）：语义检索是**稀疏向量 + 余弦**，不是神经网络 embedding；不联网、不加载模型权重。
它能处理别名、词序变化和口语改写，但不做跨语言或深层推理。

## 6. 陌生影像与网络文献（v3.2）

### 6.1 陌生影像怎么分区

库内病例走 `regions.jsonl` 的逐病例人工标注。陌生影像没有这些标注，用两层：

1. **模板选择**：`POST /api/vision/region` 接受 `atlas_id`，或 `modality/body_part/view` 自动匹配；
2. **模板定位**：`kb/scripts/build_atlas_templates.py` 把同一 atlas 下同名分区的中位坐标聚合成模板，再用与 `locate()` 相同的 coverage/purity 打分。

```bash
python3 kb/scripts/build_atlas_templates.py
curl -s http://127.0.0.1:4191/api/vision/atlases | python3 -m json.tool | head -30
curl -s -X POST http://127.0.0.1:4191/api/vision/region \
  -H 'Content-Type: application/json' \
  -d '{"atlas_id":"ATLAS-CHEST-PA-6","bbox":[0.12,0.10,0.18,0.16]}'
```

输出必须带：

- `source: "atlas_template"`；
- `honesty.human_annotated=false`；
- `n_cases < 3` 时 `warning` 提示样本偏少。

**不做的**：不把模板结果写成 `REG-xxx` 人工标注，不在前端用同一个徽标。

### 6.2 双引用怎么产生

`POST /api/ask` 加 `research=true`（或 `surface=literature`）：

1. agent 正常回答，本地引用以 `citation.kind=local` 发出；
2. 从引用里提取 `SIGN-xxx`，用 `signs.jsonl` 的英文名拼 PubMed 检索式；
3. 文献以 `citation.kind=literature` 发出，带 `PMID/DOI/journal/year/url`；
4. `done` 汇总：

```json
{
  "citations": { "local": 3, "literature": 4 },
  "literature": { "ok": true, "reason": null, "query": "...", "source": "PubMed" }
}
```

失败时 `literature.ok=false` + `reason`，前端显示“文献检索未完成”，不静默。

**中文术语不送 PubMed**：没有英文术语就返回 `no_english_term`，不返回假结果。

### 6.3 实测

| 场景 | 结果 |
| --- | --- |
| 陌生图 + 框选 + PA 模板 | 右肺上野，覆盖 100%，模板一致度 0.843，样本 74 例 |
| 磨玻璃影 + CT | 本地 2–3 条，文献 4 条，耗时 7.8–11.6s |
| 4191 代理 | `/api/vision/atlases`、`/api/vision/region`、`/api/lit/search` 均 200 |
| 前端 | `.yz-litcard=4`，无 console 错误 |
