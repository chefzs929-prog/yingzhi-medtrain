# RadHearing 双引用问答

一句话问题，四类结果：**病例问的给结论 + 影像区域 + 原文**；**“X 是什么 / 怎么找 / A 和 B 怎么区分”给词条解释 + 来源**；**超出范围的明确拒答**；**没对上的直说没对上**。

核心不在"答得像医生"，而在**每一句话都能指回具体分区和具体字**，答不了的时候不编。

---

## 何时使用

使用：

- 用户对着某张胸片问"有没有肺炎""右肺中野有什么问题""这张片子主要异常是什么"
- 用户要求"标注位置""给出依据""引用原文"
- 用户问诊断、治疗、预后、分期、精确测量、患者信息等——这时**不是不用，而是必须走拒答**

不使用：

- 非胸部 X 线（CT、MRI、超声、头颈腹四肢）
- 用户没给病例、也没法确定是哪一例，且问题不通用

---

## 工作流

1. **先定病例**
   用户给了病例 ID（如 `CASE-006`）就直接用；没给先跑一次不带 `--case` 的查询，脚本会按问题里的实体自动定位病例。

2. **调脚本，不要自己编答案**

   ```bash
   python3 .opencode/skills/radhearing-ask/scripts/ask.py "右肺中野有什么问题" --case CASE-006
   ```

   脚本输出已经是整理好的 Markdown，直接用它，**不要改写数值、不要补充脚本没给的结论**。

3. **按返回状态分三种处理**

   | 脚本返回 | 你怎么说 |
   |---|---|
   | `status=answer`（病例问） | 直接给结论 + 影像区域 + 原文引用 |
   | `status=answer`（词条解释） | 给定义 / 影像表现 / 易错点 + 文献来源链接 + 边界说明；不要补 kp_id 或字符 offset |
   | `status=refusal` | 说明为什么不能答，给出可以问什么 |
   | `status=unknown` | 直说没对上，给两三个可试的问法 |

4. **结尾必须带非诊断声明**（教学用途、不构成诊断）。

---

## 输出规范

- 病例问命中指南条款时，引用必须带 `kp_id`、字符 offset、校验码前缀——这是"可回溯"的证据，不能省略成"据指南"。
- 病例问命中逐区标注时，引用写清 `病例 id + 分区名（zone_id）`，并注明"库内逐区标注，无指南锚点"，不要补造 offset。
- 词条解释（`SIGN-xxx` / `CON-xxx`）给词条名、定义、模态与 `sources` 里的来源标题 + 链接；CT 术语要注明"胸片可辨识度有限"。
- 影像区域要写清分区名、侧别、归一化坐标（left/top/w/h），让用户能在片子上框出来。
- 拒答时先给**类别**（诊断结论/治疗建议/非胸部/问句过宽…），再给**具体理由**，最后给**替代问法**。
- 不要把拒答软化成"建议咨询医生"就完事——要讲清是哪一类能力缺失。

---

## 硬边界（不可协商）

- 不做诊断、分期、病因判断、良恶性判断。
- 不给治疗、用药、剂量、手术、住院建议。
- 不给预后、生存期。
- 不代写或签发医疗文书。
- 不做毫米/毫升级精确测量与容量估算。
- 不提供患者身份信息。
- **未提及 ≠ 正常**：来源没描述的分区，只能说"来源未描述"，不能推断为阴性。
